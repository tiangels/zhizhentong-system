## 📊 系统架构总结

### 🏗️ 整体架构

智诊通系统采用**微服务架构**，主要包含以下核心组件：

1. **前端服务** (Vue 3 + TypeScript) - 端口 8080
2. **后端服务** (FastAPI + Python) - 端口 8000
3. **向量化服务** (Embedding Service) - 端口 8001
4. **知识检索服务** (Knowledge Retrieval) - 端口 8002
5. **智能诊断服务** (Intelligent Diagnosis) - 端口 8003
6. **基础设施服务** (Elasticsearch, Kibana, ChromaDB) - 端口 9200, 5601, 8004

### 🔄 数据流向

```
用户输入 → 前端界面 → 后端API → 微服务处理 → AI模型 → 向量数据库 → 结果返回
```

### 🚀 启动顺序

1. 基础设施服务 (Elasticsearch, Kibana, ChromaDB)
2. 微服务 (向量化、检索、诊断)
3. 后端服务 (FastAPI)
4. 前端服务 (Vue 3)

### 📁 关键目录

- `codes/` - 核心代码目录
- `datas/` - 数据存储目录
- `docs/` - 项目文档目录
- `aimodels/` - AI 模型目录
