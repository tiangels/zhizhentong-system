# 智诊通前端系统完整说明文档

## 项目概述

智诊通前端系统是基于Vue 3 + TypeScript + Vite构建的现代化医疗AI诊断平台前端应用。系统采用组件化架构，提供用户友好的界面，支持智能医疗咨询、患者管理、聊天对话等核心功能。

### 技术栈

- **框架**: Vue 3 (Composition API)
- **语言**: TypeScript
- **构建工具**: Vite
- **UI组件库**: Ant Design Vue
- **状态管理**: Pinia
- **路由管理**: Vue Router
- **HTTP客户端**: Axios
- **样式**: Less

### 主要功能

- 用户认证与授权
- 智能医疗咨询对话
- 患者信息管理
- 实时聊天功能
- 系统设置管理
- 响应式界面设计

## API集成说明

### 聊天API功能

智诊通前端系统集成了完整的聊天API功能，支持与AI进行智能医疗对话。

#### 普通聊天API

- **端点**: `POST /api/v1/conversations/chat`
- **功能**: 与AI进行智能聊天，自动创建或使用现有对话
- **特点**:
  - 自动对话管理
  - RAG增强回答
  - 完善的错误处理
  - 详细的日志记录

#### 流式聊天API

- **端点**: `POST /api/v1/conversations/chat/stream`
- **功能**: 与AI进行流式智能聊天，实时接收AI回复
- **特点**:
  - Server-Sent Events (SSE) 流式响应
  - 实时内容显示
  - 自动保存到数据库
  - 连接状态管理

#### 自动对话管理

- 如果不提供 `conversation_id`，系统会自动创建新对话
- 如果提供 `conversation_id`，系统会使用现有对话继续聊天
- 自动维护对话上下文，支持多轮对话
- 智能生成对话标题

#### RAG集成

- 集成了现有的RAG服务
- 基于医疗知识库提供更准确的回答
- 支持文档检索和上下文理解
- 当RAG服务不可用时，提供备用回复

### 服务架构

智诊通系统采用微服务架构，将向量化服务和RAG服务分离，通过HTTP API进行通信。

#### 服务组件

1. **向量化服务 (Vectorization Service)**
   - **端口**: 8001
   - **功能**: 提供文本、图像、多模态向量化服务
   - **主要接口**:
     - `POST /api/v1/vectorize/text` - 文本向量化
     - `POST /api/v1/vectorize/image` - 图像向量化
     - `POST /api/v1/vectorize/multimodal` - 多模态向量化

2. **RAG服务 (RAG Service)**
   - **端口**: 8002
   - **功能**: 提供检索增强生成服务
   - **主要接口**:
     - `POST /query` - 查询接口
     - `POST /stream_query` - 流式查询接口

3. **后端API服务 (Backend API)**
   - **端口**: 8000
   - **功能**: 处理用户请求，调用RAG服务

#### 数据流程

1. **用户请求** → 后端API服务
2. **后端API** → RAG服务 (`POST /query`)
3. **RAG服务** → 向量化服务 (`POST /api/v1/vectorize/text`)
4. **向量化服务** → 返回向量化结果
5. **RAG服务** → 检索相关文档
6. **RAG服务** → 生成回答
7. **RAG服务** → 返回结果给后端API
8. **后端API** → 返回结果给用户

### 前端集成示例

#### JavaScript集成示例

```javascript
// 普通聊天
async function chatWithAI(message) {
  const response = await fetch('/api/v1/conversations/chat', {
    method: 'POST',
    headers: {
      Authorization: 'Bearer YOUR_ACCESS_TOKEN',
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      content: message,
      message_type: 'text',
    }),
  })

  if (response.ok) {
    const result = await response.json()
    return result.ai_response
  } else {
    throw new Error(`HTTP error! status: ${response.status}`)
  }
}

// 流式聊天
async function chatWithAIStream(message, onContent, onComplete) {
  const response = await fetch('/api/v1/conversations/chat/stream', {
    method: 'POST',
    headers: {
      Authorization: 'Bearer YOUR_ACCESS_TOKEN',
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      content: message,
      message_type: 'text',
    }),
  })

  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`)
  }

  const reader = response.body.getReader()
  const decoder = new TextDecoder()

  while (true) {
    const { done, value } = await reader.read()
    if (done) break

    const chunk = decoder.decode(value)
    const lines = chunk.split('\n')

    for (const line of lines) {
      if (line.startsWith('data: ')) {
        try {
          const data = JSON.parse(line.slice(6))
          if (data.type === 'content') {
            onContent(data.content)
          } else if (data.type === 'done') {
            onComplete(data.full_content)
          }
        } catch (e) {
          console.error('解析SSE数据失败:', e)
        }
      }
    }
  }
}
```

- **响应时间**: 普通聊天通常在1-3秒内完成
- **流式延迟**: 流式聊天首字符延迟通常在0.5-1秒
- **并发支持**: 支持多用户同时聊天
- **内存优化**: 流式处理减少内存占用
