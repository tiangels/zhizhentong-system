# 智诊通系统本地启动说明

## 概述

为了便于开发和调试，我们已经移除了 backend 和 embedding 服务的 Docker 部署，改为本地启动。这样可以：

- 更快的启动速度
- 更好的调试体验
- 实时代码修改生效
- 更灵活的配置管理

## 启动方式

### 1. 启动基础设施服务（Docker）

```bash
# 进入docker目录
cd codes/docker

# 启动基础设施服务（数据库、缓存、搜索引擎等）
docker compose -f docker-compose.infrastructure.yml up -d

# 或者使用旧版本docker-compose
docker-compose -f docker-compose.infrastructure.yml up -d
```

### 2. 启动应用服务（本地）

#### 启动向量化服务

```bash
cd codes/ai_models/embedding_models
./start_embedding_service.sh
```

#### 启动 RAG 检索服务

```bash
cd codes/services/knowledge_retrieval_service
./quick_start.sh
```

#### 启动后端 API 服务

```bash
cd codes/backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

#### 启动前端服务

```bash
cd codes/frontend
npm run dev
```

### 3. 一键启动（推荐）

使用项目根目录的启动脚本：

```bash
cd codes
./start-all.sh
```

## 环境变量配置

### 后端服务环境变量

在启动后端服务前，需要设置以下环境变量：

```bash
export DATABASE_URL="postgresql://zhizhentong:zhizhentong123@localhost:5432/zhizhentong"
export REDIS_URL="redis://localhost:6379/0"
export RABBITMQ_URL="amqp://zhizhentong:zhizhentong123@localhost:5672/"
export ELASTICSEARCH_URL="http://localhost:9200"
export CHROMADB_URL="http://localhost:8003"
export DEBUG=true
export LOG_LEVEL=INFO
export VECTOR_DB_TYPE=chromadb
```

## 停止服务

### 停止本地服务

```bash
# 查找并停止本地服务进程
pkill -f "uvicorn.*app.main:app"  # 停止后端服务
pkill -f "start_embedding_service"  # 停止向量化服务
pkill -f "quick_start"  # 停止RAG服务
pkill -f "npm.*dev"  # 停止前端服务
```

### 停止 Docker 服务

```bash
cd codes/docker
docker compose -f docker-compose.infrastructure.yml down
```

## 故障排除

### 1. 端口冲突

如果遇到端口被占用，可以：

- 修改服务配置文件中的端口号
- 停止占用端口的其他服务
- 使用 `lsof -i :端口号` 查看端口占用情况

### 2. 数据库连接失败

- 确保 PostgreSQL 容器正在运行：`docker ps | grep postgres`
- 检查数据库连接字符串是否正确
- 等待数据库完全启动（通常需要 30-60 秒）

### 3. 模型下载失败

- 检查网络连接
- 设置代理（如果需要）
- 手动下载模型到缓存目录

### 4. 依赖安装失败

- 确保 Python 环境正确
- 更新 pip：`pip install --upgrade pip`
- 使用国内镜像源：`pip install -i https://pypi.tuna.tsinghua.edu.cn/simple/`

## 开发建议

1. **使用虚拟环境**：为每个服务创建独立的虚拟环境
2. **日志监控**：使用 `tail -f logs/*.log` 监控服务日志
3. **热重载**：后端服务支持热重载，修改代码后自动重启
4. **调试模式**：设置 `DEBUG=true` 启用详细日志
5. **性能监控**：使用系统工具监控 CPU 和内存使用情况

## 生产环境部署

对于生产环境，建议：

1. 使用 Docker 部署所有服务
2. 配置负载均衡和反向代理
3. 设置监控和告警
4. 使用容器编排工具（如 Kubernetes）
5. 配置 SSL 证书和 HTTPS
