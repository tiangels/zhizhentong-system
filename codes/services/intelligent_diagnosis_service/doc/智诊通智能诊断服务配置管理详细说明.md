# 智诊通智能诊断服务配置管理详细说明

## 🎯 配置管理概述

配置管理是智诊通智能诊断服务的重要组成部分，负责管理服务的各种配置参数，包括模型配置、服务配置、API 配置等。通过统一的配置管理，可以实现服务的灵活部署和参数调优。

## 📁 配置目录结构

```
config/
└── diagnosis_config.json    # 主配置文件
```

#### 1.2 配置项详解

##### 1.2.1 文本摘要服务配置 (summarization_service)

```json
"summarization_service": {
  "model_path": null,
  "max_length": 300,
  "min_length": 50
}
```

**配置说明：**

- `model_path`: 模型路径，null 表示使用默认 T5-small 模型
- `max_length`: 最大摘要长度，默认 300 字符
- `min_length`: 最小摘要长度，默认 50 字符

**配置示例：**

```json
"summarization_service": {
  "model_path": "/path/to/custom/t5/model",
  "max_length": 500,
  "min_length": 100
}
```

##### 1.2.2 LLM 服务配置 (llm_service)

```json
"llm_service": {
  "device": "cuda",
  "model_path": "FreedomIntelligence/Apollo-0.5B",
  "max_length": 2048,
  "temperature": 0.7,
  "top_p": 0.9,
  "top_k": 50,
  "repetition_penalty": 1.1,
  "timeout": 600
}
```

**配置说明：**

- `device`: 设备类型，支持"cuda"、"cpu"、"auto"
- `model_path`: 模型路径，支持 HuggingFace 模型 ID 或本地路径
- `max_length`: 最大生成长度，默认 2048
- `temperature`: 温度参数，控制生成随机性，范围 0.1-2.0
- `top_p`: Top-p 采样参数，范围 0.1-1.0
- `top_k`: Top-k 采样参数，范围 1-100
- `repetition_penalty`: 重复惩罚参数，范围 1.0-2.0
- `timeout`: 超时时间，单位秒

**配置示例：**

```json
"llm_service": {
  "device": "cuda",
  "model_path": "/path/to/local/apollo/model",
  "max_length": 4096,
  "temperature": 0.8,
  "top_p": 0.95,
  "top_k": 40,
  "repetition_penalty": 1.2,
  "timeout": 1200
}
```

##### 1.2.3 服务模式配置 (service_mode)

```json
"service_mode": "optimized"
```

**可选值：**

- `"optimized"`: 优化模式，平衡性能和资源使用
- `"performance"`: 性能模式，优先考虑响应速度
- `"memory"`: 内存模式，优先考虑内存使用
- `"quality"`: 质量模式，优先考虑输出质量

##### 1.2.4 API 服务配置 (api)

```json
"api": {
  "host": "0.0.0.0",
  "port": 8003,
  "reload": false,
  "log_level": "info"
}
```

**配置说明：**

- `host`: 服务监听地址，0.0.0.0 表示监听所有接口
- `port`: 服务端口号，默认 8003
- `reload`: 是否启用热重载，开发环境建议 true
- `log_level`: 日志级别，支持 debug、info、warning、error

**配置示例：**

```json
"api": {
  "host": "127.0.0.1",
  "port": 8080,
  "reload": true,
  "log_level": "debug"
}
```

##### 1.2.5 日志配置 (logging)

```json
"logging": {
  "level": "INFO",
  "format": "%(asctime)s - %(name)s - %(levelname)s - %(message)s"
}
```

**配置说明：**

- `level`: 日志级别，支持 DEBUG、INFO、WARNING、ERROR
- `format`: 日志格式，使用 Python logging 格式字符串

**配置示例：**

```json
"logging": {
  "level": "DEBUG",
  "format": "%(asctime)s - %(name)s - %(levelname)s - %(funcName)s:%(lineno)d - %(message)s"
```

### 2. 配置验证机制

#### 2.1 配置项验证

```python
def validate_config(config: Dict[str, Any]) -> bool:
    """验证配置项"""
    try:
        # 验证摘要服务配置
        summarization_config = config.get('summarization_service', {})
        if summarization_config.get('max_length', 0) <= 0:
            raise ValueError("max_length must be positive")
        if summarization_config.get('min_length', 0) <= 0:
            raise ValueError("min_length must be positive")
        if summarization_config.get('max_length', 0) < summarization_config.get('min_length', 0):
            raise ValueError("max_length must be >= min_length")

        # 验证LLM服务配置
        llm_config = config.get('llm_service', {})
        if llm_config.get('temperature', 0) < 0 or llm_config.get('temperature', 0) > 2:
            raise ValueError("temperature must be between 0 and 2")
        if llm_config.get('top_p', 0) < 0 or llm_config.get('top_p', 0) > 1:
            raise ValueError("top_p must be between 0 and 1")
        if llm_config.get('top_k', 0) < 1:
            raise ValueError("top_k must be >= 1")
        if llm_config.get('repetition_penalty', 0) < 1:
            raise ValueError("repetition_penalty must be >= 1")

        # 验证API配置
        api_config = config.get('api', {})
        if api_config.get('port', 0) < 1 or api_config.get('port', 0) > 65535:
            raise ValueError("port must be between 1 and 65535")

        return True

    except Exception as e:
        logger.error(f"配置验证失败: {e}")
        return False
```

```python
class ConfigManager:
    """配置管理器"""

    def __init__(self, config_path: str):
        self.config_path = config_path
        self.config = self.load_config()
        self.observers = []

    def load_config(self) -> Dict[str, Any]:
        """加载配置"""
        try:
            with open(self.config_path, 'r', encoding='utf-8') as f:
                config = json.load(f)

            if self.validate_config(config):
                return config
            else:
                logger.warning("配置验证失败，使用默认配置")
                return self.get_default_config()

        except Exception as e:
            logger.error(f"加载配置失败: {e}")
            return self.get_default_config()

    def reload_config(self):
        """重新加载配置"""
        old_config = self.config.copy()
        self.config = self.load_config()

        # 检查配置是否发生变化
        if old_config != self.config:
            logger.info("配置已更新")
            self.notify_config_change(old_config, self.config)
```

### 3. 配置比较工具

```python
def compare_configs(config1_path: str, config2_path: str):
    """比较两个配置文件"""
    try:
        with open(config1_path, 'r', encoding='utf-8') as f:
            config1 = json.load(f)

        with open(config2_path, 'r', encoding='utf-8') as f:
            config2 = json.load(f)

        # 比较配置差异
        differences = find_config_differences(config1, config2)

        if differences:
            print("配置差异:")
            for key, (old_val, new_val) in differences.items():
                print(f"  {key}: {old_val} -> {new_val}")
        else:
            print("配置文件相同")

    except Exception as e:
        print(f"比较配置文件失败: {e}")

def find_config_differences(config1: Dict[str, Any], config2: Dict[str, Any]) -> Dict[str, tuple]:
    """查找配置差异"""
    differences = {}

    def compare_dict(dict1, dict2, prefix=""):
        for key in set(dict1.keys()) | set(dict2.keys()):
            full_key = f"{prefix}.{key}" if prefix else key

            if key not in dict1:
                differences[full_key] = (None, dict2[key])
            elif key not in dict2:
                differences[full_key] = (dict1[key], None)
            elif isinstance(dict1[key], dict) and isinstance(dict2[key], dict):
                compare_dict(dict1[key], dict2[key], full_key)
            elif dict1[key] != dict2[key]:
                differences[full_key] = (dict1[key], dict2[key])

    compare_dict(config1, config2)
    return differences
```

## 📊 配置最佳实践

### 1. 配置管理原则

- **单一配置源**: 使用统一的配置文件
- **环境隔离**: 不同环境使用不同配置
- **版本控制**: 配置文件纳入版本控制
- **安全考虑**: 敏感信息使用环境变量

### 2. 性能调优

- **根据硬件调整**: 根据 CPU/GPU 性能调整参数
- **内存优化**: 根据可用内存调整批处理大小
- **网络优化**: 根据网络环境调整超时时间

### 3. 安全配置
