# 智诊通智能诊断服务部署运维指南

## 🎯 部署运维概述

智诊通智能诊断服务部署运维指南提供了完整的服务部署、监控、维护和故障排除方案。该指南涵盖了从环境准备到生产部署的全流程，确保服务的高可用性和稳定性。

## 📋 部署前准备

### 1. 环境要求

#### 1.1 硬件要求

**最低配置：**

- CPU: 4 核心 2.0GHz
- 内存: 8GB RAM
- 存储: 20GB 可用空间
- 网络: 100Mbps 带宽

**推荐配置：**

- CPU: 8 核心 3.0GHz
- 内存: 16GB RAM
- 存储: 50GB 可用空间
- GPU: NVIDIA GTX 1060 或更高
- 网络: 1Gbps 带宽

**生产环境配置：**

- CPU: 16 核心 3.5GHz
- 内存: 32GB RAM
- 存储: 100GB SSD
- GPU: NVIDIA RTX 3080 或更高
- 网络: 10Gbps 带宽

#### 1.2 软件要求

**操作系统：**

- Ubuntu 20.04 LTS 或更高版本
- CentOS 8 或更高版本
- Windows 10/11 (开发环境)

**Python 环境：**

- Python 3.8+
- pip 20.0+
- conda (推荐)

**依赖软件：**

- CUDA 11.0+ (GPU 环境)
- cuDNN 8.0+ (GPU 环境)
- Docker 20.0+ (容器部署)
- Nginx 1.18+ (反向代理)

### 2. 日志管理

#### 2.1 日志配置

```python
# log_config.py
import logging
import logging.handlers
import os
from pathlib import Path

def setup_logging(log_name: str, log_level: str = "INFO"):
    """设置日志配置"""

    # 创建日志目录
    log_dir = Path("logs")
    log_dir.mkdir(exist_ok=True)

    # 配置日志格式
    formatter = logging.Formatter(
        '%(asctime)s - %(name)s - %(levelname)s - %(funcName)s:%(lineno)d - %(message)s'
    )

    # 文件处理器
    file_handler = logging.handlers.RotatingFileHandler(
        log_dir / f"{log_name}.log",
        maxBytes=100*1024*1024,  # 100MB
        backupCount=10
    )
    file_handler.setFormatter(formatter)

    # 控制台处理器
    console_handler = logging.StreamHandler()
    console_handler.setFormatter(formatter)

    # 配置根日志器
    root_logger = logging.getLogger()
    root_logger.setLevel(getattr(logging, log_level.upper()))
    root_logger.addHandler(file_handler)
    root_logger.addHandler(console_handler)

    return root_logger
```

## 🔍 故障排除

### 1. 常见问题

#### 1.1 服务启动失败

**问题**: 服务无法启动
**排查步骤**:

```bash
# 检查端口占用
netstat -tlnp | grep 8003

# 检查进程状态
ps aux | grep diagnosis_service

# 查看启动日志
journalctl -u diagnosis-service -f

# 检查配置文件
python -c "import json; json.load(open('config/diagnosis_config.json'))"
```

**解决方案**:

- 修改端口配置
- 检查依赖安装
- 验证配置文件格式
- 检查权限设置

#### 1.2 模型加载失败

**问题**: 模型无法加载
**排查步骤**:

```bash
# 检查模型文件
ls -la /opt/models/

# 检查GPU状态
nvidia-smi

# 检查CUDA环境
python -c "import torch; print(torch.cuda.is_available())"

# 检查模型路径
python -c "from transformers import AutoModel; print(AutoModel.from_pretrained('FreedomIntelligence/Apollo-0.5B'))"
```

**解决方案**:

- 重新下载模型
- 检查 GPU 驱动
- 验证 CUDA 安装
- 调整设备配置

#### 1.3 内存不足

**问题**: 内存使用过高
**排查步骤**:

```bash
# 检查内存使用
free -h
ps aux --sort=-%mem | head -10

# 检查GPU内存
nvidia-smi

# 检查进程内存
pmap -x $(pgrep -f diagnosis_service)
```

**解决方案**:

- 减少批处理大小
- 使用 CPU 模式
- 增加系统内存
- 优化模型配置

#### 1.4 响应超时

**问题**: 请求响应超时
**排查步骤**:

```bash
# 检查网络连接
netstat -an | grep 8003

# 检查服务状态
curl -f http://localhost:8003/diagnosis/health

# 检查响应时间
time curl -X POST http://localhost:8003/diagnosis/generate -d '{"query":"test"}'
```

**解决方案**:

- 增加超时时间
- 优化模型性能
- 检查网络配置
- 调整负载均衡

```bash
if [ -d "/opt/models" ]; then
    tar -czf $BACKUP_DIR/models_$DATE.tar.gz /opt/models/
fi

# 清理旧备份（保留30天）
find $BACKUP_DIR -name "*.tar.gz" -mtime +30 -delete

echo "备份完成: $BACKUP_DIR"
```

```bash
#!/bin/bash
# performance_monitor.sh

# 检查服务状态
check_service_status() {
    if systemctl is-active --quiet diagnosis-service; then
        echo "✅ 服务运行正常"
    else
        echo "❌ 服务未运行"
        return 1
    fi
}

# 检查响应时间
check_response_time() {
    local start_time=$(date +%s.%N)
    curl -s -o /dev/null -w "%{http_code}" http://localhost:8003/diagnosis/health
    local end_time=$(date +%s.%N)
    local response_time=$(echo "$end_time - $start_time" | bc)

    if (( $(echo "$response_time < 1.0" | bc -l) )); then
        echo "✅ 响应时间正常: ${response_time}s"
    else
        echo "⚠️ 响应时间较慢: ${response_time}s"
    fi
}

# 检查资源使用
check_resource_usage() {
    local cpu_usage=$(top -bn1 | grep "Cpu(s)" | awk '{print $2}' | cut -d'%' -f1)
    local memory_usage=$(free | grep Mem | awk '{printf("%.2f"), $3/$2 * 100.0}')

    if (( $(echo "$cpu_usage < 80" | bc -l) )); then
        echo "✅ CPU使用率正常: ${cpu_usage}%"
    else
        echo "⚠️ CPU使用率过高: ${cpu_usage}%"
    fi

    if (( $(echo "$memory_usage < 85" | bc -l) )); then
        echo "✅ 内存使用率正常: ${memory_usage}%"
    else
        echo "⚠️ 内存使用率过高: ${memory_usage}%"
    fi
}

# 主函数
main() {
    echo "=== 性能监控报告 ==="
    echo "检查时间: $(date)"
    echo ""

    check_service_status
    check_response_time
    check_resource_usage

    echo ""
    echo "=== 监控完成 ==="
}

main
```
