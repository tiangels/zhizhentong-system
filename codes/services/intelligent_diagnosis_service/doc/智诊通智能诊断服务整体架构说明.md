# 智诊通智能诊断服务整体架构说明

## 🎯 服务概述

智诊通智能诊断服务是智诊通系统的核心组件之一，专门负责基于大语言模型和文本摘要技术的医疗智能诊断功能。该服务整合了文本摘要、大语言模型推理和提示词工程等技术，为医疗领域提供专业的智能诊断建议和流式响应服务。

## 🏗️ 整体架构

### 架构设计原则

- **微服务架构**：独立部署，松耦合设计
- **模块化设计**：核心功能模块化，便于维护和扩展
- **流式处理**：支持实时流式响应，提升用户体验
- **多模态支持**：支持文本和图像诊断输入
- **高可用性**：完善的错误处理和健康检查机制

## 🔧 核心功能模块

### 1. 智能诊断服务 (diagnosis_service.py)

**主要功能：**

- 整合文本摘要和大语言模型服务
- 提供统一的智能诊断接口
- 支持普通和流式诊断请求
- 完善的错误处理和日志记录

**核心方法：**

- `process_diagnosis_request()` - 处理诊断请求
- `process_diagnosis_request_stream()` - 流式处理诊断请求
- `get_service_info()` - 获取服务信息
- `health_check()` - 健康检查

## 🔌 API 接口

### REST API 接口

| 接口                   | 方法 | 功能         | 参数                          |
| ---------------------- | ---- | ------------ | ----------------------------- |
| `/diagnosis/generate`  | POST | 生成诊断建议 | query, context, response_type |
| `/diagnosis/summarize` | POST | 文本摘要处理 | text, max_length              |
| `/diagnosis/stream`    | POST | 流式诊断响应 | query, context, response_type |
| `/diagnosis/health`    | GET  | 健康检查     | 无                            |
| `/diagnosis/info`      | GET  | 服务信息     | 无                            |

### 请求/响应格式

**诊断请求：**

```json
{
  "query": "我最近经常感到胸痛，这是什么原因？",
  "context": "胸痛可能由多种原因引起...",
  "response_type": "diagnosis",
  "enable_summary": true
}
```

**诊断响应：**

```json
{
  "query": "我最近经常感到胸痛，这是什么原因？",
  "summary": "胸痛可能由心血管疾病引起...",
  "diagnosis_response": "根据您描述的症状...",
  "success": true,
  "error": null
}
```

> 📖 **详细说明**：API 接口的具体实现、请求响应格式、使用示例、错误处理等详细信息，请参考 [API 接口层详细说明文档](./智诊通智能诊断服务API接口层详细说明.md)

## ⚙️ 配置管理

### 服务配置 (diagnosis_config.json)

```json
{
  "summarization_service": {
    "model_path": null,
    "max_length": 300,
    "min_length": 50
  },
  "llm_service": {
    "device": "cuda",
    "model_path": "FreedomIntelligence/Apollo-0.5B",
    "max_length": 2048,
    "temperature": 0.7,
    "top_p": 0.9,
    "top_k": 50,
    "repetition_penalty": 1.1,
    "timeout": 600
  },
  "service_mode": "optimized",
  "api": {
    "host": "0.0.0.0",
    "port": 8003,
    "reload": false,
    "log_level": "info"
  }
}
```

### 配置说明

- **summarization_service**: 文本摘要服务配置
- **llm_service**: 大语言模型服务配置
- **service_mode**: 服务运行模式
- **api**: API 服务配置
