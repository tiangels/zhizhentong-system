# 智诊通知识检索服务整体架构说明

## 📋 服务概述

智诊通知识检索服务是一个基于 RAG（检索增强生成）技术的智能医疗知识检索平台，通过整合向量检索、关键词检索和混合检索技术，为医疗领域提供精准、高效的智能问答服务。该服务是智诊通系统的核心组件，负责处理用户查询、检索相关知识并生成专业回答。

### 🎯 核心功能

- **智能检索**：基于向量相似度的语义搜索和关键词检索
- **混合检索**：整合向量检索和 ES 关键词检索，使用 RRF 融合算法
- **多模态支持**：文本、图像、语音数据的统一处理
- **跨模态检索**：图像查询返回相关文本，文本查询支持图像结果
- **用户中心化**：支持基于用户 ID 的精准检索和数据隔离
- **智能生成**：基于 Medical_Qwen3_17B 的医疗文本生成
- **流式输出**：支持实时流式响应，提供更好的用户体验
- **内容摘要**：自动将检索内容摘要到 50 字以内，提高处理效率
- **生产就绪**：完整的部署配置和监控体系

### 🏆 系统优势

✅ **统一架构**：整合 ES 检索和混合检索服务，简化系统复杂度  
✅ **智能检索**：支持向量检索、关键词检索和混合检索  
✅ **用户中心化**：支持基于用户 ID 的精准检索和数据隔离  
✅ **RRF 融合**：使用 Reciprocal Rank Fusion 算法优化检索结果  
✅ **容错机制**：网络问题自动处理，服务高可用  
✅ **完整测试**：所有核心功能验证通过  
✅ **生产就绪**：完整的部署配置和监控体系

### 🔄 RAG 工作流程

#### 阶段一：知识库构建 (embedding_models 模块)

```
原始文档 → 文档预处理 → 向量化 → 存储到向量数据库
```

```
用户查询 → 向量化 → 检索匹配 → 生成回答
```

## 🔄 核心工作流程

### 1. 知识库构建流程

```
原始数据 → 文档加载 → 数据清洗 → 文档切分 → 向量化 → 质量检查 → 索引构建
   ↓         ↓         ↓         ↓         ↓         ↓         ↓
Word/PDF  多格式    去重/过滤   Chunk    向量表示   去重/过滤   向量数据库
TXT/Excel 支持      标准化     切分      生成      质量评估   ChromaDB
```

### 2. RAG 检索流程

```
用户问题 → 向量化 → 向量检索 → 文档排序 → 上下文构建 → LLM生成 → 返回答案
    ↓         ↓         ↓         ↓         ↓         ↓
  文本输入   向量表示   相似文档   重排序    提示模板   最终答案
```

#### 2.1 问题预处理

- 文本清洗和标准化
- 关键词提取
- 意图识别

#### 2.2 向量检索

- 基于 ChromaDB 的相似度检索
- 支持多种相似度算法
- 结果重排序优化

#### 2.3 答案生成

- 基于 Medical_Qwen3_17B 模型
- 上下文感知生成
- 多轮对话支持

## 🌊 流式功能详解

### 功能概述

RAG 系统新增了两个重要功能：

1. **内容摘要功能** - 将检索到的内容先摘要到 50 字以内，提高回答质量
2. **流式输出功能** - 支持实时流式响应，提供更好的用户体验

### 流式 API 接口

#### 流式查询接口

**端点**: `POST /query/stream`

**请求参数**:

```json
{
  "question": "心肌梗死有什么症状？",
  "top_k": 5,
  "response_type": "general",
  "similarity_threshold": 200.0
}
```

**响应格式** (Server-Sent Events):

```
data: {"type": "status", "message": "开始检索相关文档..."}

data: {"type": "content", "content": "心肌梗死的主要症状包括："}

data: {"type": "content", "content": "1. 胸痛"}

data: {"type": "documents", "documents": [...]}

data: {"type": "complete", "message": "查询完成"}
```

### 性能对比

| 功能     | 常规查询     | 流式查询       |
| -------- | ------------ | -------------- |
| 响应方式 | 一次性返回   | 实时流式       |
| 用户体验 | 等待完整结果 | 实时看到进度   |
| 错误处理 | 统一错误信息 | 实时错误提示   |
| 文档展示 | 最后显示     | 检索后立即显示 |
| 适用场景 | 简单查询     | 复杂查询、演示 |

    "http://localhost:8002/query",
    json=query_data

result = response.json()
print(f"问题: {result['data']['question']}")

## ⚠️ 故障排除

### 常见问题

#### 1. 服务启动失败

- **检查端口**: 确保 8002 端口未被占用
- **检查依赖**: 运行 `pip install -r requirements.txt`
- **检查模型**: 确保模型文件存在且路径正确

#### 2. 模型加载失败

- **检查模型路径**: 确保模型文件完整
- **验证文件权限**: 确保有读取权限
- **确认磁盘空间**: 确保有足够空间

#### 3. 查询无结果

- **检查文档**: 确保已添加相关文档
- **调整参数**: 降低相似度阈值或增加 top_k 值
- **检查查询**: 确保查询内容与文档相关

#### 4. 响应时间慢

- **使用模拟服务**: 对于测试，使用 mock_rag_service.py
- **调整配置**: 减少 max_length 或 top_k 值
- **检查资源**: 确保有足够的内存和 CPU 资源

## 🔬 技术实现

### 技术概述

智诊通知识检索服务采用了多种先进的技术和算法，实现了高效、准确的智能检索和生成功能。

**核心技术：**

- **RAG 架构** - 检索增强生成，结合检索和生成的优势
- **混合检索** - 向量检索和关键词检索的融合
- **RRF 算法** - Reciprocal Rank Fusion 排序融合算法
- **流式处理** - 实时流式响应和内容摘要
- **多模态支持** - 文本、图像、语音的统一处理

**算法特色：**

- **智能切分** - 基于医疗文档特点的智能切分策略
- **相似度计算** - 多种相似度算法支持
- **结果重排序** - 基于相关性和时间权重的重排序
- **内容摘要** - 自动摘要到指定长度
