# 智诊通知识检索服务核心服务层详细说明

## 📋 核心服务层概述

核心服务层是智诊通知识检索服务的大脑，负责整合和管理所有核心业务逻辑，包括 RAG 流程协调、向量化服务调用、检索服务实现、LLM 服务集成等。该层提供了完整的检索增强生成功能，是系统功能实现的核心。

### 🎯 核心功能

- **RAG 流程整合**：端到端的检索增强生成流程
- **向量化服务管理**：文本和图像向量化处理
- **多策略检索**：语义检索、关键词检索、混合检索
- **智能生成**：基于检索结果的智能回答生成
- **流式处理**：支持实时流式响应
- **配置管理**：统一的配置管理和验证
- **日志记录**：详细的操作日志和错误追踪
- **容错机制**：多层级的容错和备用方案

### 1. 检索处理管道 (retrieval_pipeline.py)

#### 功能概述

`RetrievalPipeline` 是核心服务层的主要组件，负责整合整个 RAG 流程，提供端到端的检索增强生成功能。

#### 核心特性

- **端到端 RAG 流程**：整合向量化、检索、生成全流程
- **多模态支持**：支持文本和图像文档处理
- **批量处理**：支持批量查询和文档添加
- **流式输出**：支持实时流式响应
- **内容摘要**：自动将检索内容摘要到 50 字以内
- **系统管理**：提供统计、保存、加载、清空功能

#### 主要方法

```python
class RetrievalPipeline:
    def add_documents(self, documents: List[Dict], vectorize_images: bool = False) -> bool
    def query(self, question: str, top_k: int = 5, response_type: str = "general") -> Dict
    def chat(self, messages: List[Dict], top_k: int = 5) -> Dict
    def batch_query(self, questions: List[str], top_k: int = 5) -> List[Dict]
    def search_documents(self, query: str, search_type: str = "hybrid", top_k: int = 10) -> List[Dict]
    async def query_stream(self, question: str, top_k: int = 5) -> AsyncGenerator
    def get_system_stats(self) -> Dict
    def save_system(self, save_dir: str)
    def load_system(self, save_dir: str)
    def clear_system(self)
```

#### 使用示例

```python
# 创建RAG流程实例
rag_pipeline = RetrievalPipelineFactory.create_rag_pipeline()

# 添加文档
documents = [
    {
        "content": "心肌梗死是由于冠状动脉急性闭塞导致心肌缺血坏死的心血管疾病。",
        "title": "心肌梗死定义",
        "category": "心血管疾病",
        "source": "医学教科书"
    }
]
rag_pipeline.add_documents(documents)

# 查询
result = rag_pipeline.query("什么是心肌梗死？", top_k=5)
print(f"Answer: {result['answer']}")

# 流式查询
async for chunk in rag_pipeline.query_stream("心肌梗死症状", top_k=3):
    print(f"Chunk: {chunk}")
```

### 2. 向量服务 (vector_service.py)

#### 功能概述

`VectorService` 负责文本和图像的向量化处理，是检索功能的基础组件。

#### 服务特性

- **统一向量化**：调用构建知识库模块的向量化服务，避免重复实现
- **多模型支持**：支持 SentenceTransformer、TF-IDF 等多种模型
- **容错机制**：提供多层级的备用方案
- **ChromaDB 集成**：使用 ChromaDB 作为向量数据库
- **批量处理**：支持批量文本和图像向量化

#### 主要方法

```python
class VectorService:
    def text_to_vector(self, text: str) -> np.ndarray
    def batch_text_to_vectors(self, texts: List[str]) -> np.ndarray
    def image_to_vector(self, image_path: str) -> np.ndarray
    def batch_image_to_vectors(self, image_paths: List[str]) -> np.ndarray
    def add_vectors_to_db(self, vectors: np.ndarray, metadata: List[Dict])
    def search_similar_vectors(self, query_vector: np.ndarray, top_k: int = 10) -> tuple
    def chunk_document(self, text: str, metadata: Dict = None) -> List[Dict]
    def process_document_with_chunking(self, text: str, metadata: Dict = None) -> Dict
```

#### 容错机制

1. **优先使用构建知识库模块**：调用 `embedding_models` 的向量化服务
2. **备用本地模型**：使用 SentenceTransformer 或 HuggingFace 模型
3. **简单 TF-IDF**：最后的备用方案
4. **零向量返回**：确保系统不会崩溃

#### 使用示例

```python
# 创建向量服务
vector_service = VectorService(config)

# 文本向量化
query_vector = vector_service.text_to_vector("什么是心肌梗死？")

# 批量向量化
texts = ["文本1", "文本2", "文本3"]
vectors = vector_service.batch_text_to_vectors(texts)

# 相似度检索
similar_vectors, scores = vector_service.search_similar_vectors(query_vector, top_k=5)
```

### 3. 检索服务 (retrieval_service.py)

#### 功能概述

`RetrievalService` 实现多种检索策略，包括语义检索、混合检索、重排序检索等。

#### 功能特性

- **多种检索策略**：语义检索、混合检索、重排序检索
- **ChromaDB 集成**：使用 ChromaDB 进行高效向量检索
- **相似度过滤**：基于阈值过滤低质量结果
- **关键词搜索**：支持传统关键词匹配
- **元数据管理**：完整的文档元数据存储和查询

#### 检索策略

```python
class RetrievalService:
    def retrieve_documents(self, query_vector: np.ndarray, top_k: int = 10,
                          strategy: str = None, query_text: str = None) -> List[Dict]
    def _semantic_retrieval(self, query_vector: np.ndarray, top_k: int, query_text: str) -> List[Dict]
    def _hybrid_retrieval(self, query_vector: np.ndarray, top_k: int, query_text: str) -> List[Dict]
    def _rerank_retrieval(self, query_vector: np.ndarray, top_k: int, query_text: str) -> List[Dict]
    def search_by_keywords(self, keywords: List[str], top_k: int = 10) -> List[Dict]
```

#### 检索模式与优先级（默认 hybrid）

- **语义检索（semantic）**：对查询向量化，仅在 ChromaDB 中做相似度检索；适合通用医疗知识召回
- **ES 检索（es）**：按用户维度（`user_id`/`owner_user_id`）与关键词权重匹配，并应用时间权重；适合用户病例/就诊记录
- **混合检索（hybrid，默认）**：
  - 步骤 1：优先执行 ES，取前 `max_es_results`
  - 步骤 2：执行语义检索，取前 `max_vector_results`
  - 步骤 3：使用 RRF 融合（`es_weight` 默认 0.6，`rrf_k` 默认 60），输出统一排序并截断到 `top_k`
  - 容错：任一侧无结果即退化为另一侧；两侧皆空返回空列表

#### 使用示例

```python
# 初始化检索服务
retrieval_service = RetrievalService(config)

# 添加文档
retrieval_service.add_documents(vectors, documents)

# 语义检索
results = retrieval_service.retrieve_documents(query_vector, top_k=5, strategy="semantic")

# 关键词搜索
keyword_results = retrieval_service.search_by_keywords(["胸痛", "心肌梗死"], top_k=5)
```

### 4. 大语言模型服务 (llm_service.py)

#### 功能概述

`LLMService` 负责基于检索结果生成智能回答，支持多种响应类型和流式生成。

#### 功能特性

- **Qwen2 医疗模型**：基于 Qwen2-0.5B-Medical-MLX 的专业医疗模型
- **多种响应类型**：支持诊断、建议、解释等不同类型的医疗响应
- **流式生成**：支持实时流式文本生成
- **超时处理**：内置超时机制，防止长时间等待
- **上下文对话**：支持多轮对话和上下文理解

#### 主要方法

```python
class LLMService:
    def generate_text(self, prompt: str, max_new_tokens: int = 128, timeout: int = 600) -> str
    def generate_medical_response(self, query: str, context: str = "", response_type: str = "diagnosis") -> str
    def generate_general_response(self, query: str, response_type: str = "general") -> str
    def chat_with_context(self, messages: List[Dict], context: str = "") -> str
    def generate_medical_response_stream(self, query: str, context: str = "", response_type: str = "general")
    def summarize_text(self, text: str, max_length: int = 200) -> str
    def extract_keywords(self, text: str) -> List[str]
```

#### 提示词模板

- **诊断提示词**：包含症状分析、诊断依据、检查建议、注意事项
- **建议提示词**：包含健康建议、预防措施、生活方式建议、就医指导
- **解释提示词**：包含详细解释、相关机制、临床表现、治疗原则
- **通用提示词**：包含症状分析、专业建议、就医指导、注意事项

#### 使用示例

```python

    response_type="diagnosis"
```

## 🔄 核心工作流程

### 1. 文档添加流程

```
用户输入文档 → 文档预处理 → 向量化处理 → 存储到数据库 → 返回结果
     ↓              ↓           ↓            ↓           ↓
   文档列表       格式验证     向量生成     索引更新     成功确认
```

### 2. 查询处理流程

```
用户查询 → 向量化 → 检索匹配 → 结果排序 → 上下文构建 → LLM生成 → 返回答案
    ↓        ↓        ↓         ↓         ↓         ↓        ↓
  文本输入   向量表示   相似文档   重排序    提示模板   最终答案   格式化
```

### 3. 流式查询流程

```
用户查询 → 状态更新 → 向量化 → 文档检索 → 内容摘要 → 流式生成 → 完成通知
    ↓        ↓        ↓        ↓         ↓         ↓        ↓
  文本输入   进度反馈   向量表示   相似文档   摘要内容   实时输出   结束标记
```

### 4. 批量处理流程

```
批量查询 → 并行处理 → 结果汇总 → 格式统一 → 返回结果
    ↓        ↓        ↓         ↓         ↓
  查询列表   多线程    结果合并   格式检查   批量响应
```

## 📊 性能优化

### 1. 向量检索优化

- **ChromaDB 索引**：使用高效的向量索引
- **批量处理**：支持批量向量化处理
- **缓存机制**：缓存常用查询结果
- **相似度计算**：优化的相似度计算算法

## ⚠️ 故障排除

### 1. 常见问题

#### 向量化服务问题

- **问题**：向量化失败
- **原因**：模型文件缺失或路径错误
- **解决方案**：检查模型路径，确保文件完整

#### 检索服务问题

- **问题**：检索无结果
- **原因**：相似度阈值过高或文档不足
- **解决方案**：降低阈值或增加文档

#### LLM 服务问题

- **问题**：生成失败
- **原因**：模型加载失败或内存不足
