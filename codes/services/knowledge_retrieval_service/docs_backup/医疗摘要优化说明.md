# 🏥 医疗摘要提示词优化说明

## 📋 优化概述

基于您的专业建议，我们对医疗文本摘要的提示词进行了全面优化，使其更符合医疗领域的专业要求和规范。

## 🔄 优化对比

### ❌ **之前的提示词**

```python
input_text = f"Summarize the following medical information concisely and professionally: {text}"
```

**问题：**

- 过于简单，缺乏专业性
- 没有结构化指导
- 无医疗术语规范
- 缺乏质量控制标准

### ✅ **优化后的提示词**

```python
def _build_medical_summary_prompt(self, conversation_history: str, rag_content: str = "") -> str:
    prompt = f"""请基于以下两部分内容，生成一份医疗领域专业摘要：

【对话历史】
{conversation_history}

【RAG检索内容】
{rag_content if rag_content else "无相关检索内容"}

### 摘要要求：
1. **核心要素**：需涵盖患者关键信息（年龄、性别、核心症状、既往病史）、医生初步判断、RAG检索中与当前病例高度相关的医学依据（如指南建议、文献结论）。

2. **字数限制**：中文摘要控制在200-300字，突出重点，避免冗余表述。

3. **医疗规范**：
   - 术语使用准确（如"心肌梗死"而非"心梗"缩写，除非首次出现时标注）；
   - 避免绝对化诊断表述（如用"考虑××疾病可能"而非"确诊××疾病"）；
   - 不包含未经证实的推测，所有医学观点需与RAG检索内容一致；

4. **结构清晰**：按"患者信息→核心症状→初步分析→参考依据"逻辑组织，便于快速获取关键信息。

请严格遵循医疗文本的严谨性和规范性，确保摘要既简洁又完整反映对话核心与检索依据。"""
```

## 🎯 核心改进

### 1. **结构化指导**

- **患者信息**：年龄、性别、核心症状、既往病史
- **医生判断**：初步诊断和判断
- **医学依据**：RAG 检索的相关指南和文献
- **逻辑组织**：按医疗流程组织信息

### 2. **医疗术语规范**

- ✅ 使用标准医学术语（"心肌梗死"而非"心梗"）
- ✅ 避免绝对化表述（"考虑可能"而非"确诊"）
- ✅ 基于检索内容，避免推测

### 3. **质量控制**

- **字数控制**：200-300 字，突出重点
- **内容完整性**：涵盖关键医疗要素
- **专业性**：符合医疗文本规范

### 2. **优化的生成参数**

```python
outputs = self.model.generate(
    inputs.input_ids,
    max_length=max_length,
    min_length=100,  # 增加最小长度确保摘要完整性

    top_p=0.85,      # 调整top-p采样

)
```

## 📊 使用示例

### 输入示例

```python
# 医患对话历史
conversation_history = """
患者：医生，我最近总是感觉胸闷，特别是晚上睡觉的时候，有时候还会出汗。
医生：请问您这种症状持续多长时间了？有没有其他伴随症状？
患者：大概有半个月了，有时候还会感觉心跳很快，特别是活动后。
医生：您之前有没有心脏病史？家族中有人患心脏病吗？
患者：我父亲有高血压，我自己没有心脏病史。
医生：根据您的症状描述，我建议您做心电图和心脏彩超检查，排除心脏疾病。
"""

# RAG检索内容
rag_content = """
根据《中国心血管病报告》，胸闷、心悸、出汗等症状可能与冠心病、心律失常等疾病相关。
建议进行心电图、心脏彩超、心肌酶等检查以明确诊断。
对于有家族心脏病史的患者，应更加重视心血管疾病的筛查。
"""
```

### 输出示例

```
患者信息：中年患者，主诉胸闷、心悸、出汗症状持续半个月，有家族高血压病史。
核心症状：胸闷（夜间加重）、心悸、出汗，活动后症状明显。
初步分析：医生考虑心血管疾病可能，建议心电图和心脏彩超检查排除心脏疾病。
参考依据：根据《中国心血管病报告》，此类症状可能与冠心病、心律失常相关，建议完善相关检查以明确诊断。
```
