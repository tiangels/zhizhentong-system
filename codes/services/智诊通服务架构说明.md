# 智诊通服务架构说明

## 📋 概述

智诊通系统采用微服务架构，将不同功能模块拆分为独立的服务，每个服务专注于特定的业务领域，通过 API 接口进行通信。

## 🏗️ 服务架构

### 服务概览

| 服务名称       | 端口 | 功能描述            | 状态      |
| -------------- | ---- | ------------------- | --------- |
| 向量化服务     | 8001 | 文本/图像向量化处理 | ✅ 运行中 |
| 知识检索服务   | 8002 | 知识检索和问答      | ✅ 运行中 |
| 智能诊断服务   | 8003 | 医疗智能诊断        | ✅ 运行中 |
| 多模态处理服务 | -    | 多模态数据处理      | 🚧 开发中 |
| 会话管理服务   | -    | 会话状态管理        | 🚧 开发中 |

## 🔧 核心服务详解

### 1. 向量化服务 (embedding_service)

**功能**: 将文本、图像等数据转换为向量表示

**核心特性**:

- 多模态向量化（文本、图像）
- 医疗领域优化
- 高性能批量处理
- 可扩展模型支持

**详细说明**: 请参考 [向量化服务整体架构说明](./embedding_service/doc/智诊通向量化服务整体架构说明.md)

**启动方式**:

```bash
cd codes/services/embedding_service
python start_embedding_service.py
```

### 2. 知识检索服务 (knowledge_retrieval_service)

**功能**: 提供知识检索、问答和混合检索功能

**核心特性**:

- 向量检索
- ES 关键词检索
- RRF 混合融合
- 用户中心化检索
- 多模态检索

**详细说明**: 请参考 [知识检索服务整体架构说明](./knowledge_retrieval_service/doc/智诊通知识检索服务整体架构说明.md)

**启动方式**:

```bash
cd codes/services/knowledge_retrieval_service
python start_retrieval_service.py
```

### 3. 智能诊断服务 (intelligent_diagnosis_service)

**功能**: 提供医疗智能诊断和文本摘要功能

**核心特性**:

- 医疗文本摘要
- 智能诊断建议生成
- 医疗知识解释
- 诊断流程管理

**详细说明**: 请参考 [智能诊断服务整体架构说明](./intelligent_diagnosis_service/doc/智诊通智能诊断服务整体架构说明.md)

**启动方式**:

```bash
cd codes/services/intelligent_diagnosis_service
python start_diagnosis_service.py
```

### 4. 多模态处理服务 (multi_model_processing_service)

**功能**: 处理多模态数据（文本、图像、语音等）

**状态**: 🚧 开发中

**详细说明**: 请参考服务目录下的文档

### 5. 会话管理服务 (session_management_service)

**功能**: 管理用户会话状态和上下文

**状态**: 🚧 开发中

**详细说明**: 请参考服务目录下的文档

## 🔄 服务间通信

### 服务依赖关系

```
前端服务 → 后端服务 → 智能诊断服务
                ↓
        知识检索服务 → 向量化服务
```

### API 调用流程

1. **用户请求** → 前端服务
2. **业务逻辑** → 后端服务
3. **知识检索** → 知识检索服务
4. **向量化处理** → 向量化服务
5. **智能诊断** → 智能诊断服务
6. **结果返回** → 用户界面

## 🛠️ 开发指南

### 添加新服务

1. 在 `codes/services/` 下创建服务目录
2. 按照现有服务结构组织代码
3. 添加 `doc/` 目录和整体架构说明文档
4. 实现健康检查端点
5. 更新服务启动脚本

### 服务间调用

```python
import requests

# 调用向量化服务
response = requests.post(
    "http://localhost:8001/vectorize/text",
    json={"text": "医疗文本"}
)

# 调用知识检索服务
response = requests.post(
    "http://localhost:8002/search",
    json={"query": "查询内容", "top_k": 10}
)

# 调用智能诊断服务
response = requests.post(
    "http://localhost:8003/diagnosis/generate",
    json={"text": "诊断文本"}
)
```

## 🔍 故障排查

### 常见问题

1. **服务启动失败**

   - 检查端口是否被占用
   - 检查配置文件是否正确
   - 查看服务日志

2. **服务间调用失败**

   - 检查服务是否正常运行
   - 检查网络连接
   - 验证 API 接口格式

3. **性能问题**
   - 检查系统资源使用情况
   - 优化模型加载策略
   - 调整并发参数
