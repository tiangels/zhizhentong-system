## 1. 概述

### 1.1 配置管理简介

智诊通向量化服务配置管理系统是一个统一、灵活、安全的配置管理解决方案，为整个向量化服务提供配置的统一管理、动态更新、安全保护和监控功能。

#### 1.1.1 主要功能

- **统一配置管理**: 集中管理所有服务配置，支持多种配置源
- **动态配置更新**: 支持配置的热更新，无需重启服务
- **配置验证**: 提供完整的配置验证机制，确保配置正确性
- **安全保护**: 支持配置加密、访问控制和审计功能
- **模板系统**: 提供配置模板和生成器，简化配置管理
- **监控告警**: 实时监控配置状态，提供健康检查和指标统计

#### 1.1.2 适用场景

- 微服务架构中的配置管理
- 多环境部署的配置管理
- 敏感配置的安全管理
- 配置的版本控制和回滚
- 配置的集中监控和审计

### 1.2 设计目标

#### 1.2.1 核心目标

1. **统一性**: 提供统一的配置管理接口和标准
2. **灵活性**: 支持多种配置源和格式
3. **安全性**: 确保配置数据的安全性和完整性
4. **可扩展性**: 支持插件化扩展和自定义配置源
5. **高性能**: 优化配置加载和更新性能
6. **易用性**: 提供简单易用的 API 和工具

#### 1.2.2 设计原则

- **单一职责**: 每个组件专注于特定功能
- **开闭原则**: 对扩展开放，对修改封闭
- **依赖倒置**: 依赖抽象而非具体实现
- **接口隔离**: 提供细粒度的接口设计
- **配置分离**: 配置与代码分离，支持外部化配置

### 2.1 ConfigManager 配置管理器

#### 2.1.1 文件概述

- **文件路径**: `config_management/base/config_manager.py`
- **主要功能**: 提供统一的配置管理接口
- **继承关系**: 基础抽象类

#### 2.1.2 核心功能

```python
from abc import ABC, abstractmethod
from typing import Dict, Any, Optional, List, Union
import time
import threading
from collections import defaultdict

class ConfigManager(ABC):
    """配置管理器基类"""

    def __init__(self, config: Dict[str, Any] = None):
        """
        初始化配置管理器

        Args:
            config: 配置参数
        """
        self.config = config or {}
        self._config_cache = {}
        self._config_lock = threading.RLock()
        self._config_history = []
        self._listeners = defaultdict(list)
        self._initialized = False

        # 统计信息
        self.stats = {
            'load_count': 0,
            'update_count': 0,
            'cache_hits': 0,
            'cache_misses': 0,
            'error_count': 0
        }

    def initialize(self) -> bool:
        """
        初始化配置管理器

        Returns:
            bool: 初始化是否成功
        """
        try:
            if not self._initialized:
                self._setup()
                self._initialized = True
            return True
        except Exception as e:
            self.stats['error_count'] += 1
            raise

    @abstractmethod
    def _setup(self):
        """子类实现具体的初始化逻辑"""
        pass

    def get_config(self, key: str, default: Any = None) -> Any:
        """
        获取配置值

        Args:
            key: 配置键，支持点号分隔的嵌套键
            default: 默认值

        Returns:
            Any: 配置值
        """
        if not self._initialized:
            self.initialize()

        with self._config_lock:
            # 检查缓存
            cache_key = f"{key}:{default}"
            if cache_key in self._config_cache:
                self.stats['cache_hits'] += 1
                return self._config_cache[cache_key]

            self.stats['cache_misses'] += 1

            # 获取配置值
            value = self._get_config_value(key, default)

            # 缓存结果
            self._config_cache[cache_key] = value
            return value

    @abstractmethod
    def _get_config_value(self, key: str, default: Any = None) -> Any:
        """子类实现具体的配置获取逻辑"""
        pass

    def set_config(self, key: str, value: Any, validate: bool = True) -> bool:
        """
        设置配置值

        Args:
            key: 配置键
            value: 配置值
            validate: 是否验证配置

        Returns:
            bool: 设置是否成功
        """
        if not self._initialized:
            self.initialize()

        try:
            with self._config_lock:
                # 验证配置
                if validate and not self._validate_config(key, value):
                    return False

                # 记录历史
                old_value = self._get_config_value(key)
                self._config_history.append({
                    'key': key,
                    'old_value': old_value,
                    'new_value': value,
                    'timestamp': time.time()
                })

                # 设置配置
                success = self._set_config_value(key, value)

                if success:
                    # 清除缓存
                    self._clear_cache(key)

                    # 通知监听器
                    self._notify_listeners(key, old_value, value)

                    self.stats['update_count'] += 1

                return success

        except Exception as e:
            self.stats['error_count'] += 1
            raise

    @abstractmethod
    def _set_config_value(self, key: str, value: Any) -> bool:
        """子类实现具体的配置设置逻辑"""
        pass

    def _validate_config(self, key: str, value: Any) -> bool:
        """
        验证配置值

        Args:
            key: 配置键
            value: 配置值

        Returns:
            bool: 验证是否通过
        """
        # 基础验证逻辑，子类可以重写
        return True

    def _clear_cache(self, key: str = None):
        """清除缓存"""
        if key:
            # 清除特定键的缓存
            keys_to_remove = [k for k in self._config_cache.keys() if k.startswith(f"{key}:")]
            for k in keys_to_remove:
                del self._config_cache[k]
        else:
            # 清除所有缓存
            self._config_cache.clear()

    def _notify_listeners(self, key: str, old_value: Any, new_value: Any):
        """通知配置变更监听器"""
        for listener in self._listeners.get(key, []):
            try:
                listener(key, old_value, new_value)
            except Exception as e:
                # 记录监听器错误，但不影响配置更新
                pass

    def add_listener(self, key: str, listener: callable):
        """
        添加配置变更监听器

        Args:
            key: 配置键
            listener: 监听器函数
        """
        self._listeners[key].append(listener)

    def remove_listener(self, key: str, listener: callable):
        """
        移除配置变更监听器

        Args:
            key: 配置键
            listener: 监听器函数
        """
        if listener in self._listeners.get(key, []):
            self._listeners[key].remove(listener)

    def get_config_history(self, key: str = None, limit: int = 100) -> List[Dict[str, Any]]:
        """
        获取配置历史记录

        Args:
            key: 配置键，None表示所有键
            limit: 返回记录数量限制

        Returns:
            List[Dict[str, Any]]: 配置历史记录
        """
        history = self._config_history
        if key:
            history = [h for h in history if h['key'] == key]

        return history[-limit:]

    def rollback_config(self, key: str, steps: int = 1) -> bool:
        """
        回滚配置

        Args:
            key: 配置键
            steps: 回滚步数

        Returns:
            bool: 回滚是否成功
        """
        history = self.get_config_history(key, steps + 1)
        if len(history) < steps + 1:
            return False

        target_history = history[-(steps + 1)]
        return self.set_config(key, target_history['old_value'], validate=False)

    def get_stats(self) -> Dict[str, Any]:
        """获取统计信息"""
        return {
            **self.stats,
            'cache_size': len(self._config_cache),
            'history_size': len(self._config_history),
            'listener_count': sum(len(listeners) for listeners in self._listeners.values())
        }

    def cleanup(self):
        """清理资源"""
        self._config_cache.clear()
        self._listeners.clear()
        self._initialized = False
```

### 2.2 ConfigValidator 配置验证器

#### 2.2.1 文件概述

- **文件路径**: `config_management/base/config_validator.py`
- **主要功能**: 提供配置验证功能
- **继承关系**: 基础抽象类

#### 2.2.2 核心功能

```python
from abc import ABC, abstractmethod
from typing import Dict, Any, List, Union, Callable, Optional
import re
import json
from datetime import datetime

class ConfigValidator(ABC):
    """配置验证器基类"""

    def __init__(self, config: Dict[str, Any] = None):
        """
        初始化配置验证器

        Args:
            config: 验证器配置
        """
        self.config = config or {}
        self._validation_rules = {}
        self._custom_validators = {}
        self._setup()

    def _setup(self):
        """初始化验证器"""
        self._setup_default_rules()

    def _setup_default_rules(self):
        """设置默认验证规则"""
        self._validation_rules = {
            'required': self._validate_required,
            'type': self._validate_type,
            'range': self._validate_range,
            'pattern': self._validate_pattern,
            'enum': self._validate_enum,
            'length': self._validate_length,
            'custom': self._validate_custom
        }

    def validate(self, config_data: Dict[str, Any], schema: Dict[str, Any]) -> Dict[str, Any]:
        """
        验证配置数据

        Args:
            config_data: 配置数据
            schema: 验证模式

        Returns:
            Dict[str, Any]: 验证结果
        """
        errors = []
        warnings = []

        try:
            self._validate_recursive(config_data, schema, '', errors, warnings)
        except Exception as e:
            errors.append(f"验证过程发生错误: {str(e)}")

        return {
            'valid': len(errors) == 0,
            'errors': errors,
            'warnings': warnings,
            'timestamp': datetime.now().isoformat()
        }

    def _validate_recursive(self, data: Any, schema: Dict[str, Any],
                          path: str, errors: List[str], warnings: List[str]):
        """递归验证配置数据"""
        for rule_name, rule_config in schema.items():
            if rule_name in self._validation_rules:
                try:
                    self._validation_rules[rule_name](data, rule_config, path, errors, warnings)
                except Exception as e:
                    errors.append(f"{path}: 验证规则 '{rule_name}' 执行失败: {str(e)}")
            elif rule_name == 'properties' and isinstance(data, dict):
                # 处理嵌套对象
                for key, value in data.items():
                    if key in rule_config:
                        self._validate_recursive(value, rule_config[key], f"{path}.{key}", errors, warnings)
            elif rule_name == 'items' and isinstance(data, list):
                # 处理数组
                for i, item in enumerate(data):
                    self._validate_recursive(item, rule_config, f"{path}[{i}]", errors, warnings)

    def _validate_required(self, data: Any, rule_config: Any, path: str,
                          errors: List[str], warnings: List[str]):
        """验证必填字段"""
        if rule_config and data is None:
            errors.append(f"{path}: 必填字段不能为空")

    def _validate_type(self, data: Any, rule_config: Union[type, str], path: str,
                      errors: List[str], warnings: List[str]):
        """验证数据类型"""
        if data is None:
            return

        expected_type = rule_config
        if isinstance(rule_config, str):
            type_mapping = {
                'string': str,
                'integer': int,
                'float': float,
                'boolean': bool,
                'array': list,
                'object': dict
            }
            expected_type = type_mapping.get(rule_config, str)

        if not isinstance(data, expected_type):
            errors.append(f"{path}: 期望类型 {expected_type.__name__}, 实际类型 {type(data).__name__}")

    def _validate_range(self, data: Any, rule_config: Dict[str, Any], path: str,
                       errors: List[str], warnings: List[str]):
        """验证数值范围"""
        if not isinstance(data, (int, float)):
            return

        if 'min' in rule_config and data < rule_config['min']:
            errors.append(f"{path}: 值 {data} 小于最小值 {rule_config['min']}")

        if 'max' in rule_config and data > rule_config['max']:
            errors.append(f"{path}: 值 {data} 大于最大值 {rule_config['max']}")

    def _validate_pattern(self, data: Any, rule_config: str, path: str,
                         errors: List[str], warnings: List[str]):
        """验证正则表达式模式"""
        if not isinstance(data, str):
            return

        if not re.match(rule_config, data):
            errors.append(f"{path}: 值 '{data}' 不匹配模式 '{rule_config}'")

    def _validate_enum(self, data: Any, rule_config: List[Any], path: str,
                      errors: List[str], warnings: List[str]):
        """验证枚举值"""
        if data not in rule_config:
            errors.append(f"{path}: 值 '{data}' 不在允许的枚举值中: {rule_config}")

    def _validate_length(self, data: Any, rule_config: Dict[str, int], path: str,
                        errors: List[str], warnings: List[str]):
        """验证长度"""
        if isinstance(data, str):
            length = len(data)
        elif isinstance(data, (list, dict)):
            length = len(data)
        else:
            return

        if 'min' in rule_config and length < rule_config['min']:
            errors.append(f"{path}: 长度 {length} 小于最小长度 {rule_config['min']}")

        if 'max' in rule_config and length > rule_config['max']:
            errors.append(f"{path}: 长度 {length} 大于最大长度 {rule_config['max']}")

    def _validate_custom(self, data: Any, rule_config: str, path: str,
                        errors: List[str], warnings: List[str]):
        """验证自定义规则"""
        if rule_config in self._custom_validators:
            validator = self._custom_validators[rule_config]
            if not validator(data):
                errors.append(f"{path}: 自定义验证失败: {rule_config}")
        else:
            warnings.append(f"{path}: 未知的自定义验证规则: {rule_config}")

    def add_custom_validator(self, name: str, validator: Callable[[Any], bool]):
        """
        添加自定义验证器

        Args:
            name: 验证器名称
            validator: 验证函数
        """
        self._custom_validators[name] = validator

    def remove_custom_validator(self, name: str):
        """
        移除自定义验证器

        Args:
            name: 验证器名称
        """
        if name in self._custom_validators:
            del self._custom_validators[name]

    def validate_config_file(self, file_path: str, schema: Dict[str, Any]) -> Dict[str, Any]:
        """
        验证配置文件

        Args:
            file_path: 配置文件路径
            schema: 验证模式

        Returns:
            Dict[str, Any]: 验证结果
        """
        try:
            with open(file_path, 'r', encoding='utf-8') as f:
                if file_path.endswith('.json'):
                    config_data = json.load(f)
                else:
                    # 支持其他格式的配置文件
                    config_data = self._load_config_file(file_path, f)

            return self.validate(config_data, schema)

        except Exception as e:
            return {
                'valid': False,
                'errors': [f"配置文件加载失败: {str(e)}"],
                'warnings': [],
                'timestamp': datetime.now().isoformat()
            }

    @abstractmethod
    def _load_config_file(self, file_path: str, file_handle) -> Dict[str, Any]:
        """子类实现具体的配置文件加载逻辑"""
        pass
```

### 2.3 ConfigLoader 配置加载器

#### 2.3.1 文件概述

- **文件路径**: `config_management/utils/config_loader.py`
- **主要功能**: 提供配置加载功能
- **继承关系**: 工具类

#### 2.3.2 核心功能

```python
from typing import Dict, Any, List, Optional, Union
import os
import json
import yaml
import toml
from pathlib import Path
import importlib.util
from datetime import datetime

class ConfigLoader:
    """配置加载器"""

    def __init__(self, config: Dict[str, Any] = None):
        """
        初始化配置加载器

        Args:
            config: 加载器配置
        """
        self.config = config or {}
        self._supported_formats = {
            '.json': self._load_json,
            '.yaml': self._load_yaml,
            '.yml': self._load_yaml,
            '.toml': self._load_toml,
            '.py': self._load_python,
            '.ini': self._load_ini,
            '.conf': self._load_ini
        }
        self._load_cache = {}
        self._cache_enabled = self.config.get('cache_enabled', True)
        self._cache_ttl = self.config.get('cache_ttl', 300)  # 5分钟

    def load_config(self, source: Union[str, Dict[str, Any]],
                   format_type: str = None) -> Dict[str, Any]:
        """
        加载配置

        Args:
            source: 配置源（文件路径或配置字典）
            format_type: 配置格式类型

        Returns:
            Dict[str, Any]: 配置数据
        """
        if isinstance(source, dict):
            return source

        if isinstance(source, str):
            # 文件路径
            if os.path.isfile(source):
                return self._load_config_file(source, format_type)
            elif os.path.isdir(source):
                return self._load_config_directory(source)
            else:
                raise FileNotFoundError(f"配置源不存在: {source}")

        raise ValueError(f"不支持的配置源类型: {type(source)}")

    def _load_config_file(self, file_path: str, format_type: str = None) -> Dict[str, Any]:
        """加载配置文件"""
        file_path = os.path.abspath(file_path)

        # 检查缓存
        if self._cache_enabled and file_path in self._load_cache:
            cached_data, cached_time = self._load_cache[file_path]
            if datetime.now().timestamp() - cached_time < self._cache_ttl:
                return cached_data

        # 确定文件格式
        if format_type:
            file_ext = f".{format_type}"
        else:
            file_ext = Path(file_path).suffix.lower()

        if file_ext not in self._supported_formats:
            raise ValueError(f"不支持的配置文件格式: {file_ext}")

        try:
            # 加载配置文件
            loader_func = self._supported_formats[file_ext]
            config_data = loader_func(file_path)

            # 缓存结果
            if self._cache_enabled:
                self._load_cache[file_path] = (config_data, datetime.now().timestamp())

            return config_data

        except Exception as e:
            raise RuntimeError(f"加载配置文件失败 {file_path}: {str(e)}")

    def _load_config_directory(self, dir_path: str) -> Dict[str, Any]:
        """加载配置目录"""
        config_data = {}

        for root, dirs, files in os.walk(dir_path):
            for file in files:
                file_path = os.path.join(root, file)
                file_ext = Path(file_path).suffix.lower()

                if file_ext in self._supported_formats:
                    try:
                        file_config = self._load_config_file(file_path)
                        # 使用相对路径作为键
                        rel_path = os.path.relpath(file_path, dir_path)
                        key = rel_path.replace(os.sep, '.').replace(file_ext, '')
                        config_data[key] = file_config
                    except Exception as e:
                        # 记录错误但继续处理其他文件
                        print(f"警告: 加载配置文件失败 {file_path}: {str(e)}")

        return config_data

    def _load_json(self, file_path: str) -> Dict[str, Any]:
        """加载JSON配置文件"""
        with open(file_path, 'r', encoding='utf-8') as f:
            return json.load(f)

    def _load_yaml(self, file_path: str) -> Dict[str, Any]:
        """加载YAML配置文件"""
        with open(file_path, 'r', encoding='utf-8') as f:
            return yaml.safe_load(f)

    def _load_toml(self, file_path: str) -> Dict[str, Any]:
        """加载TOML配置文件"""
        with open(file_path, 'r', encoding='utf-8') as f:
            return toml.load(f)

    def _load_python(self, file_path: str) -> Dict[str, Any]:
        """加载Python配置文件"""
        spec = importlib.util.spec_from_file_location("config", file_path)
        module = importlib.util.module_from_spec(spec)
        spec.loader.exec_module(module)

        # 提取配置变量
        config_data = {}
        for attr_name in dir(module):
            if not attr_name.startswith('_'):
                attr_value = getattr(module, attr_name)
                if not callable(attr_value):
                    config_data[attr_name] = attr_value

        return config_data

    def _load_ini(self, file_path: str) -> Dict[str, Any]:
        """加载INI配置文件"""
        import configparser

        config = configparser.ConfigParser()
        config.read(file_path, encoding='utf-8')

        config_data = {}
        for section_name in config.sections():
            config_data[section_name] = {}
            for key, value in config.items(section_name):
                config_data[section_name][key] = value

        return config_data

    def merge_configs(self, configs: List[Dict[str, Any]],
                     merge_strategy: str = 'override') -> Dict[str, Any]:
        """
        合并多个配置

        Args:
            configs: 配置列表
            merge_strategy: 合并策略 ('override', 'merge', 'append')

        Returns:
            Dict[str, Any]: 合并后的配置
        """
        if not configs:
            return {}

        result = configs[0].copy()

        for config in configs[1:]:
            result = self._merge_two_configs(result, config, merge_strategy)

        return result

    def _merge_two_configs(self, config1: Dict[str, Any], config2: Dict[str, Any],
                          strategy: str) -> Dict[str, Any]:
        """合并两个配置"""
        result = config1.copy()

        for key, value in config2.items():
            if key in result:
                if isinstance(result[key], dict) and isinstance(value, dict):
                    if strategy == 'merge':
                        result[key] = self._merge_two_configs(result[key], value, strategy)
                    else:
                        result[key] = value
                elif isinstance(result[key], list) and isinstance(value, list):
                    if strategy == 'append':
                        result[key] = result[key] + value
                    else:
                        result[key] = value
                else:
                    result[key] = value
            else:
                result[key] = value

        return result

    def clear_cache(self):
        """清除加载缓存"""
        self._load_cache.clear()

    def get_cache_info(self) -> Dict[str, Any]:
        """获取缓存信息"""
        return {
            'cache_enabled': self._cache_enabled,
            'cache_ttl': self._cache_ttl,
            'cached_files': list(self._load_cache.keys()),
            'cache_size': len(self._load_cache)
        }
```

### 3.1 FileConfigStorage 文件配置存储

#### 3.1.1 文件概述

- **文件路径**: `config_management/storage/file_storage.py`
- **主要功能**: 提供基于文件的配置存储功能

#### 3.1.2 核心功能

```python
from typing import Dict, Any, Optional, List
import os
import json
import yaml
import toml
from pathlib import Path
import threading
from ..base.config_manager import ConfigManager

class FileConfigStorage(ConfigManager):
    """文件配置存储"""

    def _setup(self):
        """初始化文件配置存储"""
        self.config_file = self.config.get('config_file', 'config.json')
        self.config_dir = self.config.get('config_dir', './config')
        self.file_format = self.config.get('format', 'json')
        self.auto_save = self.config.get('auto_save', True)
        self.backup_enabled = self.config.get('backup_enabled', True)
        self.backup_count = self.config.get('backup_count', 5)

        # 确保配置目录存在
        os.makedirs(self.config_dir, exist_ok=True)

        # 配置文件路径
        if not os.path.isabs(self.config_file):
            self.config_file = os.path.join(self.config_dir, self.config_file)

        # 加载现有配置
        self._load_config()

    def _load_config(self):
        """加载配置文件"""
        if os.path.exists(self.config_file):
            try:
                with open(self.config_file, 'r', encoding='utf-8') as f:
                    if self.file_format == 'json':
                        self._config_data = json.load(f)
                    elif self.file_format in ['yaml', 'yml']:
                        self._config_data = yaml.safe_load(f)
                    elif self.file_format == 'toml':
                        self._config_data = toml.load(f)
                    else:
                        raise ValueError(f"不支持的配置文件格式: {self.file_format}")
            except Exception as e:
                self.logger.error(f"加载配置文件失败: {e}")
                self._config_data = {}
        else:
            self._config_data = {}

    def _save_config(self):
        """保存配置文件"""
        if not self.auto_save:
            return

        try:
            # 创建备份
            if self.backup_enabled and os.path.exists(self.config_file):
                self._create_backup()

            # 保存配置
            with open(self.config_file, 'w', encoding='utf-8') as f:
                if self.file_format == 'json':
                    json.dump(self._config_data, f, indent=2, ensure_ascii=False)
                elif self.file_format in ['yaml', 'yml']:
                    yaml.dump(self._config_data, f, default_flow_style=False, allow_unicode=True)
                elif self.file_format == 'toml':
                    toml.dump(self._config_data, f)
                else:
                    raise ValueError(f"不支持的配置文件格式: {self.file_format}")

            self.stats['save_count'] = self.stats.get('save_count', 0) + 1

        except Exception as e:
            self.stats['error_count'] += 1
            raise RuntimeError(f"保存配置文件失败: {e}")

    def _create_backup(self):
        """创建配置文件备份"""
        try:
            backup_dir = os.path.join(self.config_dir, 'backups')
            os.makedirs(backup_dir, exist_ok=True)

            # 生成备份文件名
            import time
            timestamp = int(time.time())
            backup_file = os.path.join(backup_dir, f"config_backup_{timestamp}.{self.file_format}")

            # 复制文件
            import shutil
            shutil.copy2(self.config_file, backup_file)

            # 清理旧备份
            self._cleanup_old_backups(backup_dir)

        except Exception as e:
            self.logger.warning(f"创建备份失败: {e}")

    def _cleanup_old_backups(self, backup_dir: str):
        """清理旧备份文件"""
        try:
            backup_files = []
            for file in os.listdir(backup_dir):
                if file.startswith('config_backup_') and file.endswith(f'.{self.file_format}'):
                    file_path = os.path.join(backup_dir, file)
                    backup_files.append((file_path, os.path.getmtime(file_path)))

            # 按修改时间排序
            backup_files.sort(key=lambda x: x[1], reverse=True)

            # 删除多余的备份文件
            for file_path, _ in backup_files[self.backup_count:]:
                os.remove(file_path)

        except Exception as e:
            self.logger.warning(f"清理备份文件失败: {e}")

    def _get_config_value(self, key: str, default: Any = None) -> Any:
        """获取配置值"""
        keys = key.split('.')
        value = self._config_data

        for k in keys:
            if isinstance(value, dict) and k in value:
                value = value[k]
            else:
                return default

        return value

    def _set_config_value(self, key: str, value: Any) -> bool:
        """设置配置值"""
        try:
            keys = key.split('.')
            config = self._config_data

            # 导航到目标位置
            for k in keys[:-1]:
                if k not in config:
                    config[k] = {}
                config = config[k]

            # 设置值
            config[keys[-1]] = value

            # 保存配置
            self._save_config()

            return True

        except Exception as e:
            self.stats['error_count'] += 1
            return False

    def get_all_config(self) -> Dict[str, Any]:
        """获取所有配置"""
        return self._config_data.copy()

    def set_all_config(self, config_data: Dict[str, Any]) -> bool:
        """设置所有配置"""
        try:
            self._config_data = config_data.copy()
            self._save_config()
            return True
        except Exception as e:
            self.stats['error_count'] += 1
            return False

    def delete_config(self, key: str) -> bool:
        """删除配置项"""
        try:
            keys = key.split('.')
            config = self._config_data

            # 导航到目标位置
            for k in keys[:-1]:
                if k not in config:
                    return False
                config = config[k]

            # 删除值
            if keys[-1] in config:
                del config[keys[-1]]
                self._save_config()
                return True

            return False

        except Exception as e:
            self.stats['error_count'] += 1
            return False

    def export_config(self, file_path: str, format_type: str = None) -> bool:
        """导出配置到文件"""
        try:
            format_type = format_type or self.file_format

            with open(file_path, 'w', encoding='utf-8') as f:
                if format_type == 'json':
                    json.dump(self._config_data, f, indent=2, ensure_ascii=False)
                elif format_type in ['yaml', 'yml']:
                    yaml.dump(self._config_data, f, default_flow_style=False, allow_unicode=True)
                elif format_type == 'toml':
                    toml.dump(self._config_data, f)
                else:
                    raise ValueError(f"不支持的导出格式: {format_type}")

            return True

        except Exception as e:
            self.stats['error_count'] += 1
            return False

    def import_config(self, file_path: str, merge: bool = True) -> bool:
        """从文件导入配置"""
        try:
            with open(file_path, 'r', encoding='utf-8') as f:
                if file_path.endswith('.json'):
                    imported_data = json.load(f)
                elif file_path.endswith(('.yaml', '.yml')):
                    imported_data = yaml.safe_load(f)
                elif file_path.endswith('.toml'):
                    imported_data = toml.load(f)
                else:
                    raise ValueError(f"不支持的导入格式: {file_path}")

            if merge:
                # 合并配置
                self._config_data = self._merge_configs(self._config_data, imported_data)
            else:
                # 替换配置
                self._config_data = imported_data

            self._save_config()
            return True

        except Exception as e:
            self.stats['error_count'] += 1
            return False

    def _merge_configs(self, base_config: Dict[str, Any],
                      new_config: Dict[str, Any]) -> Dict[str, Any]:
        """合并配置"""
        result = base_config.copy()

        for key, value in new_config.items():
            if key in result and isinstance(result[key], dict) and isinstance(value, dict):
                result[key] = self._merge_configs(result[key], value)
            else:
                result[key] = value

        return result
```

### 3.2 DatabaseConfigStorage 数据库配置存储

#### 3.2.1 文件概述

- **文件路径**: `config_management/storage/database_storage.py`
- **主要功能**: 提供基于数据库的配置存储功能
- **继承关系**: 继承自 ConfigManager

#### 3.2.2 核心功能

```python
from typing import Dict, Any, Optional, List
import sqlite3
import json
import threading
from datetime import datetime
from ..base.config_manager import ConfigManager

class DatabaseConfigStorage(ConfigManager):
    """数据库配置存储"""

    def _setup(self):
        """初始化数据库配置存储"""
        self.db_path = self.config.get('db_path', 'config.db')
        self.table_name = self.config.get('table_name', 'config')
        self.connection_pool_size = self.config.get('connection_pool_size', 10)
        self.connection_timeout = self.config.get('connection_timeout', 30)

        # 连接池
        self._connection_pool = []
        self._pool_lock = threading.Lock()

        # 初始化数据库
        self._init_database()

    def _init_database(self):
        """初始化数据库"""
        conn = self._get_connection()
        try:
            cursor = conn.cursor()
            cursor.execute(f'''
                CREATE TABLE IF NOT EXISTS {self.table_name} (
                    id INTEGER PRIMARY KEY AUTOINCREMENT,
                    key TEXT UNIQUE NOT NULL,
                    value TEXT NOT NULL,
                    type TEXT NOT NULL,
                    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
                    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
                )
            ''')

            # 创建索引
            cursor.execute(f'CREATE INDEX IF NOT EXISTS idx_key ON {self.table_name}(key)')
            cursor.execute(f'CREATE INDEX IF NOT EXISTS idx_updated_at ON {self.table_name}(updated_at)')

            conn.commit()
        finally:
            self._return_connection(conn)

    def _get_connection(self):
        """获取数据库连接"""
        with self._pool_lock:
            if self._connection_pool:
                return self._connection_pool.pop()

        return sqlite3.connect(self.db_path, timeout=self.connection_timeout)

    def _return_connection(self, conn):
        """归还数据库连接"""
        with self._pool_lock:
            if len(self._connection_pool) < self.connection_pool_size:
                self._connection_pool.append(conn)
            else:
                conn.close()

    def _get_config_value(self, key: str, default: Any = None) -> Any:
        """获取配置值"""
        conn = self._get_connection()
        try:
            cursor = conn.cursor()
            cursor.execute(f'SELECT value, type FROM {self.table_name} WHERE key = ?', (key,))
            row = cursor.fetchone()

            if row:
                value_str, value_type = row
                return self._deserialize_value(value_str, value_type)
            else:
                return default

        finally:
            self._return_connection(conn)

    def _set_config_value(self, key: str, value: Any) -> bool:
        """设置配置值"""
        conn = self._get_connection()
        try:
            cursor = conn.cursor()
            value_str, value_type = self._serialize_value(value)

            cursor.execute(f'''
                INSERT OR REPLACE INTO {self.table_name}
                (key, value, type, updated_at)
                VALUES (?, ?, ?, ?)
            ''', (key, value_str, value_type, datetime.now()))

            conn.commit()
            return True

        except Exception as e:
            conn.rollback()
            self.stats['error_count'] += 1
            return False
        finally:
            self._return_connection(conn)

    def _serialize_value(self, value: Any) -> tuple:
        """序列化配置值"""
        if isinstance(value, (dict, list)):
            return json.dumps(value, ensure_ascii=False), 'json'
        elif isinstance(value, str):
            return value, 'string'
        elif isinstance(value, int):
            return str(value), 'integer'
        elif isinstance(value, float):
            return str(value), 'float'
        elif isinstance(value, bool):
            return str(value), 'boolean'
        else:
            return str(value), 'string'

    def _deserialize_value(self, value_str: str, value_type: str) -> Any:
        """反序列化配置值"""
        if value_type == 'json':
            return json.loads(value_str)
        elif value_type == 'string':
            return value_str
        elif value_type == 'integer':
            return int(value_str)
        elif value_type == 'float':
            return float(value_str)
        elif value_type == 'boolean':
            return value_str.lower() == 'true'
        else:
            return value_str

    def get_all_config(self) -> Dict[str, Any]:
        """获取所有配置"""
        conn = self._get_connection()
        try:
            cursor = conn.cursor()
            cursor.execute(f'SELECT key, value, type FROM {self.table_name}')
            rows = cursor.fetchall()

            config_data = {}
            for key, value_str, value_type in rows:
                config_data[key] = self._deserialize_value(value_str, value_type)

            return config_data

        finally:
            self._return_connection(conn)

    def delete_config(self, key: str) -> bool:
        """删除配置项"""
        conn = self._get_connection()
        try:
            cursor = conn.cursor()
            cursor.execute(f'DELETE FROM {self.table_name} WHERE key = ?', (key,))
            conn.commit()
            return cursor.rowcount > 0

        except Exception as e:
            conn.rollback()
            self.stats['error_count'] += 1
            return False
        finally:
            self._return_connection(conn)

    def get_config_history(self, key: str = None, limit: int = 100) -> List[Dict[str, Any]]:
        """获取配置历史记录"""
        conn = self._get_connection()
        try:
            cursor = conn.cursor()

            if key:
                cursor.execute(f'''
                    SELECT key, value, type, updated_at
                    FROM {self.table_name}
                    WHERE key = ?
                    ORDER BY updated_at DESC
                    LIMIT ?
                ''', (key, limit))
            else:
                cursor.execute(f'''
                    SELECT key, value, type, updated_at
                    FROM {self.table_name}
                    ORDER BY updated_at DESC
                    LIMIT ?
                ''', (limit,))

            rows = cursor.fetchall()
            history = []

            for key, value_str, value_type, updated_at in rows:
                history.append({
                    'key': key,
                    'value': self._deserialize_value(value_str, value_type),
                    'updated_at': updated_at
                })

            return history

        finally:
            self._return_connection(conn)

    def search_config(self, pattern: str) -> List[Dict[str, Any]]:
        """搜索配置项"""
        conn = self._get_connection()
        try:
            cursor = conn.cursor()
            cursor.execute(f'''
                SELECT key, value, type, updated_at
                FROM {self.table_name}
                WHERE key LIKE ?
                ORDER BY key
            ''', (f'%{pattern}%',))

            rows = cursor.fetchall()
            results = []

            for key, value_str, value_type, updated_at in rows:
                results.append({
                    'key': key,
                    'value': self._deserialize_value(value_str, value_type),
                    'updated_at': updated_at
                })

            return results

        finally:
            self._return_connection(conn)

    def cleanup_old_configs(self, days: int = 30) -> int:
        """清理旧配置"""
        conn = self._get_connection()
        try:
            cursor = conn.cursor()
            cursor.execute(f'''
                DELETE FROM {self.table_name}
                WHERE updated_at < datetime('now', '-{days} days')
            ''')
            conn.commit()
            return cursor.rowcount

        except Exception as e:
            conn.rollback()
            self.stats['error_count'] += 1
            return 0
        finally:
            self._return_connection(conn)

    def get_database_stats(self) -> Dict[str, Any]:
        """获取数据库统计信息"""
        conn = self._get_connection()
        try:
            cursor = conn.cursor()

            # 总配置数
            cursor.execute(f'SELECT COUNT(*) FROM {self.table_name}')
            total_configs = cursor.fetchone()[0]

            # 按类型统计
            cursor.execute(f'SELECT type, COUNT(*) FROM {self.table_name} GROUP BY type')
            type_stats = dict(cursor.fetchall())

            # 数据库大小
            cursor.execute("SELECT page_count * page_size as size FROM pragma_page_count(), pragma_page_size()")
            db_size = cursor.fetchone()[0]

            return {
                'total_configs': total_configs,
                'type_stats': type_stats,
                'database_size': db_size,
                'connection_pool_size': len(self._connection_pool)
            }

        finally:
            self._return_connection(conn)
```

```python
from typing import Dict, Any, Optional, List
import os
import json
import re
from ..base.config_manager import ConfigManager

class EnvironmentConfigStorage(ConfigManager):
    """环境变量配置存储"""

    def _setup(self):
        """初始化环境变量配置存储"""
        self.prefix = self.config.get('prefix', 'APP_')
        self.separator = self.config.get('separator', '__')
        self.case_sensitive = self.config.get('case_sensitive', False)
        self.auto_cast = self.config.get('auto_cast', True)
        self.read_only = self.config.get('read_only', True)

        # 加载环境变量
        self._load_environment_vars()

    def _load_environment_vars(self):
        """加载环境变量"""
        self._env_config = {}

        for key, value in os.environ.items():
            if key.startswith(self.prefix):
                config_key = key[len(self.prefix):]

                # 处理嵌套键
                if self.separator in config_key:
                    config_key = config_key.replace(self.separator, '.')

                # 处理大小写
                if not self.case_sensitive:
                    config_key = config_key.lower()

                # 转换值类型
                if self.auto_cast:
                    value = self._cast_value(value)

                self._env_config[config_key] = value

    def _cast_value(self, value: str) -> Any:
        """转换值类型"""
        if not value:
            return value

        # 尝试转换为数字
        if value.isdigit():
            return int(value)

        try:
            if '.' in value:
                return float(value)
        except ValueError:
            pass

        # 尝试转换为布尔值
        if value.lower() in ('true', 'false'):
            return value.lower() == 'true'

        # 尝试解析JSON
        if value.startswith(('{', '[')):
            try:
                return json.loads(value)
            except json.JSONDecodeError:
                pass

        # 返回字符串
        return value

    def _get_config_value(self, key: str, default: Any = None) -> Any:
        """获取配置值"""
        # 处理大小写
        if not self.case_sensitive:
            key = key.lower()

        return self._env_config.get(key, default)

    def _set_config_value(self, key: str, value: Any) -> bool:
        """设置配置值"""
        if self.read_only:
            return False

        try:
            # 处理大小写
            if not self.case_sensitive:
                key = key.lower()

            # 序列化值
            if isinstance(value, (dict, list)):
                value_str = json.dumps(value, ensure_ascii=False)
            else:
                value_str = str(value)

            # 构建环境变量名
            env_key = self.prefix + key.replace('.', self.separator)
            if not self.case_sensitive:
                env_key = env_key.upper()

            # 设置环境变量
            os.environ[env_key] = value_str

            # 更新内部配置
            self._env_config[key] = value

            return True

        except Exception as e:
            self.stats['error_count'] += 1
            return False

    def get_all_config(self) -> Dict[str, Any]:
        """获取所有配置"""
        return self._env_config.copy()

    def refresh_config(self):
        """刷新配置"""
        self._load_environment_vars()

    def export_to_env_file(self, file_path: str, format_type: str = 'env') -> bool:
        """导出配置到环境变量文件"""
        try:
            with open(file_path, 'w', encoding='utf-8') as f:
                if format_type == 'env':
                    # .env 格式
                    for key, value in self._env_config.items():
                        env_key = self.prefix + key.replace('.', self.separator)
                        if not self.case_sensitive:
                            env_key = env_key.upper()

                        # 转义值
                        if isinstance(value, str) and (' ' in value or '"' in value):
                            value = f'"{value}"'

                        f.write(f'{env_key}={value}\n')

                elif format_type == 'bash':
                    # bash 格式
                    f.write('#!/bin/bash\n\n')
                    for key, value in self._env_config.items():
                        env_key = self.prefix + key.replace('.', self.separator)
                        if not self.case_sensitive:
                            env_key = env_key.upper()

                        f.write(f'export {env_key}="{value}"\n')

                else:
                    raise ValueError(f"不支持的导出格式: {format_type}")

            return True

        except Exception as e:
            self.stats['error_count'] += 1
            return False

    def load_from_env_file(self, file_path: str) -> bool:
        """从环境变量文件加载配置"""
        try:
            with open(file_path, 'r', encoding='utf-8') as f:
                for line in f:
                    line = line.strip()
                    if line and not line.startswith('#'):
                        # 解析键值对
                        if '=' in line:
                            key, value = line.split('=', 1)
                            key = key.strip()
                            value = value.strip()

                            # 移除引号
                            if value.startswith('"') and value.endswith('"'):
                                value = value[1:-1]
                            elif value.startswith("'") and value.endswith("'"):
                                value = value[1:-1]

                            # 设置环境变量
                            os.environ[key] = value

            # 刷新配置
            self._load_environment_vars()
            return True

        except Exception as e:
            self.stats['error_count'] += 1
            return False

    def get_env_vars(self) -> Dict[str, str]:
        """获取所有环境变量"""
        env_vars = {}
        for key, value in os.environ.items():
            if key.startswith(self.prefix):
                env_vars[key] = value
        return env_vars

    def validate_env_vars(self, required_vars: List[str]) -> Dict[str, Any]:
        """验证必需的环境变量"""
        missing_vars = []
        invalid_vars = []

        for var in required_vars:
            env_key = self.prefix + var.replace('.', self.separator)
            if not self.case_sensitive:
                env_key = env_key.upper()

            if env_key not in os.environ:
                missing_vars.append(var)
            elif not os.environ[env_key].strip():
                invalid_vars.append(var)

        return {
            'valid': len(missing_vars) == 0 and len(invalid_vars) == 0,
            'missing_vars': missing_vars,
            'invalid_vars': invalid_vars
        }
```

```python
from typing import Dict, Any, List, Callable, Optional
import os
import time
import threading
from pathlib import Path
from watchdog.observers import Observer
from watchdog.events import FileSystemEventHandler

class ConfigWatcher:
    """配置监听器"""

    def __init__(self, config: Dict[str, Any] = None):
        """
        初始化配置监听器

        Args:
            config: 监听器配置
        """
        self.config = config or {}
        self.watch_paths = self.config.get('watch_paths', [])
        self.watch_recursive = self.config.get('watch_recursive', True)
        self.debounce_time = self.config.get('debounce_time', 1.0)
        self.file_extensions = self.config.get('file_extensions', ['.json', '.yaml', '.yml', '.toml'])

        self.observer = None
        self.event_handler = None
        self.callbacks = []
        self.last_modified = {}
        self.watching = False
        self._lock = threading.Lock()

    def add_callback(self, callback: Callable[[str, str], None]):
        """
        添加变更回调函数

        Args:
            callback: 回调函数，参数为 (file_path, event_type)
        """
        self.callbacks.append(callback)

    def remove_callback(self, callback: Callable[[str, str], None]):
        """
        移除变更回调函数

        Args:
            callback: 回调函数
        """
        if callback in self.callbacks:
            self.callbacks.remove(callback)

    def start_watching(self):
        """开始监听"""
        if self.watching:
            return

        try:
            self.observer = Observer()
            self.event_handler = ConfigFileHandler(self)

            for path in self.watch_paths:
                if os.path.exists(path):
                    self.observer.schedule(
                        self.event_handler,
                        path,
                        recursive=self.watch_recursive
                    )

            self.observer.start()
            self.watching = True

        except Exception as e:
            raise RuntimeError(f"启动配置监听失败: {e}")

    def stop_watching(self):
        """停止监听"""
        if not self.watching:
            return

        try:
            if self.observer:
                self.observer.stop()
                self.observer.join()
                self.observer = None

            self.watching = False

        except Exception as e:
            raise RuntimeError(f"停止配置监听失败: {e}")

    def _handle_file_change(self, file_path: str, event_type: str):
        """处理文件变更"""
        # 检查文件扩展名
        if not self._is_config_file(file_path):
            return

        # 防抖处理
        current_time = time.time()
        if file_path in self.last_modified:
            if current_time - self.last_modified[file_path] < self.debounce_time:
                return

        self.last_modified[file_path] = current_time

        # 调用回调函数
        for callback in self.callbacks:
            try:
                callback(file_path, event_type)
            except Exception as e:
                print(f"回调函数执行失败: {e}")

    def _is_config_file(self, file_path: str) -> bool:
        """检查是否为配置文件"""
        if not self.file_extensions:
            return True

        file_ext = Path(file_path).suffix.lower()
        return file_ext in self.file_extensions

    def add_watch_path(self, path: str):
        """添加监听路径"""
        if path not in self.watch_paths:
            self.watch_paths.append(path)

            # 如果正在监听，添加新的监听路径
            if self.watching and self.observer and os.path.exists(path):
                self.observer.schedule(
                    self.event_handler,
                    path,
                    recursive=self.watch_recursive
                )

    def remove_watch_path(self, path: str):
        """移除监听路径"""
        if path in self.watch_paths:
            self.watch_paths.remove(path)

    def get_watch_status(self) -> Dict[str, Any]:
        """获取监听状态"""
        return {
            'watching': self.watching,
            'watch_paths': self.watch_paths,
            'callback_count': len(self.callbacks),
            'last_modified': self.last_modified.copy()
        }

class ConfigFileHandler(FileSystemEventHandler):
    """配置文件事件处理器"""

    def __init__(self, watcher: ConfigWatcher):
        self.watcher = watcher

    def on_modified(self, event):
        if not event.is_directory:
            self.watcher._handle_file_change(event.src_path, 'modified')

    def on_created(self, event):
        if not event.is_directory:
            self.watcher._handle_file_change(event.src_path, 'created')

    def on_deleted(self, event):
        if not event.is_directory:
            self.watcher._handle_file_change(event.src_path, 'deleted')
```

```python
from typing import Dict, Any, List, Optional, Callable
import time
import threading
from datetime import datetime
from .config_loader import ConfigLoader

class ConfigReloader:
    """配置重载器"""

    def __init__(self, config: Dict[str, Any] = None):
        """
        初始化配置重载器

        Args:
            config: 重载器配置
        """
        self.config = config or {}
        self.config_sources = self.config.get('config_sources', [])
        self.reload_interval = self.config.get('reload_interval', 60)  # 秒
        self.auto_reload = self.config.get('auto_reload', False)
        self.reload_on_change = self.config.get('reload_on_change', True)

        self.config_loader = ConfigLoader(self.config.get('loader_config', {}))
        self.current_config = {}
        self.config_history = []
        self.reload_callbacks = []
        self.reload_thread = None
        self.reloading = False
        self._lock = threading.RLock()

        # 统计信息
        self.stats = {
            'reload_count': 0,
            'success_count': 0,
            'error_count': 0,
            'last_reload': None,
            'last_error': None
        }

    def add_reload_callback(self, callback: Callable[[Dict[str, Any], Dict[str, Any]], None]):
        """
        添加重载回调函数

        Args:
            callback: 回调函数，参数为 (old_config, new_config)
        """
        self.reload_callbacks.append(callback)

    def remove_reload_callback(self, callback: Callable[[Dict[str, Any], Dict[str, Any]], None]):
        """
        移除重载回调函数

        Args:
            callback: 回调函数
        """
        if callback in self.reload_callbacks:
            self.reload_callbacks.remove(callback)

    def start_auto_reload(self):
        """启动自动重载"""
        if self.auto_reload and not self.reload_thread:
            self.reload_thread = threading.Thread(target=self._auto_reload_loop, daemon=True)
            self.reload_thread.start()

    def stop_auto_reload(self):
        """停止自动重载"""
        self.auto_reload = False
        if self.reload_thread:
            self.reload_thread.join(timeout=5)
            self.reload_thread = None

    def _auto_reload_loop(self):
        """自动重载循环"""
        while self.auto_reload:
            try:
                self.reload_config()
                time.sleep(self.reload_interval)
            except Exception as e:
                self.stats['error_count'] += 1
                self.stats['last_error'] = str(e)
                time.sleep(self.reload_interval)

    def reload_config(self) -> bool:
        """
        重载配置

        Returns:
            bool: 重载是否成功
        """
        if self.reloading:
            return False

        with self._lock:
            self.reloading = True

            try:
                # 加载新配置
                new_config = self._load_all_configs()

                # 检查配置是否变更
                if self._config_changed(self.current_config, new_config):
                    old_config = self.current_config.copy()

                    # 更新配置
                    self.current_config = new_config

                    # 记录历史
                    self._record_config_history(old_config, new_config)

                    # 调用回调函数
                    self._notify_reload_callbacks(old_config, new_config)

                    self.stats['success_count'] += 1
                    self.stats['reload_count'] += 1
                    self.stats['last_reload'] = datetime.now().isoformat()

                    return True
                else:
                    return True

            except Exception as e:
                self.stats['error_count'] += 1
                self.stats['last_error'] = str(e)
                return False
            finally:
                self.reloading = False

    def _load_all_configs(self) -> Dict[str, Any]:
        """加载所有配置源"""
        all_configs = []

        for source in self.config_sources:
            try:
                config_data = self.config_loader.load_config(source)
                all_configs.append(config_data)
            except Exception as e:
                print(f"加载配置源失败 {source}: {e}")

        # 合并配置
        if all_configs:
            return self.config_loader.merge_configs(all_configs)
        else:
            return {}

    def _config_changed(self, old_config: Dict[str, Any], new_config: Dict[str, Any]) -> bool:
        """检查配置是否变更"""
        return old_config != new_config

    def _record_config_history(self, old_config: Dict[str, Any], new_config: Dict[str, Any]):
        """记录配置历史"""
        self.config_history.append({
            'timestamp': datetime.now().isoformat(),
            'old_config': old_config.copy(),
            'new_config': new_config.copy(),
            'changes': self._get_config_changes(old_config, new_config)
        })

        # 限制历史记录数量
        max_history = self.config.get('max_history', 100)
        if len(self.config_history) > max_history:
            self.config_history = self.config_history[-max_history:]

    def _get_config_changes(self, old_config: Dict[str, Any], new_config: Dict[str, Any]) -> Dict[str, Any]:
        """获取配置变更详情"""
        changes = {
            'added': {},
            'modified': {},
            'deleted': {}
        }

        # 检查新增和修改
        for key, value in new_config.items():
            if key not in old_config:
                changes['added'][key] = value
            elif old_config[key] != value:
                changes['modified'][key] = {
                    'old': old_config[key],
                    'new': value
                }

        # 检查删除
        for key in old_config:
            if key not in new_config:
                changes['deleted'][key] = old_config[key]

        return changes

    def _notify_reload_callbacks(self, old_config: Dict[str, Any], new_config: Dict[str, Any]):
        """通知重载回调函数"""
        for callback in self.reload_callbacks:
            try:
                callback(old_config, new_config)
            except Exception as e:
                print(f"重载回调函数执行失败: {e}")

    def get_current_config(self) -> Dict[str, Any]:
        """获取当前配置"""
        return self.current_config.copy()

    def get_config_history(self, limit: int = 10) -> List[Dict[str, Any]]:
        """获取配置历史"""
        return self.config_history[-limit:]

    def rollback_config(self, steps: int = 1) -> bool:
        """
        回滚配置

        Args:
            steps: 回滚步数

        Returns:
            bool: 回滚是否成功
        """
        if len(self.config_history) < steps:
            return False

        target_history = self.config_history[-(steps + 1)]
        old_config = target_history['old_config']

        with self._lock:
            self.current_config = old_config
            self._record_config_history(self.current_config, old_config)
            self._notify_reload_callbacks(self.current_config, old_config)

        return True

    def add_config_source(self, source: str):
        """添加配置源"""
        if source not in self.config_sources:
            self.config_sources.append(source)

    def remove_config_source(self, source: str):
        """移除配置源"""
        if source in self.config_sources:
            self.config_sources.remove(source)

    def get_stats(self) -> Dict[str, Any]:
        """获取统计信息"""
        return {
            **self.stats,
            'config_sources': len(self.config_sources),
            'history_size': len(self.config_history),
            'callback_count': len(self.reload_callbacks),
            'reloading': self.reloading
        }
```

### 4.3 ConfigNotifier 配置通知器

```python
import threading
import json
from datetime import datetime
from enum import Enum

class NotificationType(Enum):
    """通知类型"""
    CONFIG_CHANGED = "config_changed"
    CONFIG_RELOADED = "config_reloaded"
    CONFIG_ERROR = "config_error"
    CONFIG_WARNING = "config_warning"

class ConfigNotifier:
    """配置通知器"""

        """

        self.notification_level = self.config.get('level', 'INFO')
        self.format_type = self.config.get('format', 'json')

        self.buffer_thread = None
        self.buffering = False

        # 统计信息

            'successful_notifications': 0,

            'buffer_overflows': 0
        }

            callback: 回调函数
        """

        Args:
            notification_type: 通知类型
            callback: 回调函数
        """

            if callback in self.subscribers[notification_type]:
                self.subscribers[notification_type].remove(callback)

    def notify(self, notification_type: NotificationType, data: Dict[str, Any],
              level: str = 'INFO', channels: List[str] = None):
        """
        发送通知

        Args:
            notification_type: 通知类型
            data: 通知数据
            level: 通知级别
            channels: 通知通道
        """
        channels = channels or self.notification_channels

        notification = {
            'type': notification_type.value,
            'level': level,
            'data': data,
            'timestamp': datetime.now().isoformat(),
            'channels': channels
        }

        # 检查通知级别
        if not self._should_notify(level):
            return

        # 添加到缓冲区
        self._add_to_buffer(notification)

        # 立即通知订阅者
        self._notify_subscribers(notification_type, notification)

        self.stats['total_notifications'] += 1

    def _should_notify(self, level: str) -> bool:
        """检查是否应该发送通知"""
        level_priority = {
            'DEBUG': 0,
            'INFO': 1,
            'WARNING': 2,
            'ERROR': 3,
            'CRITICAL': 4
        }

        current_priority = level_priority.get(self.notification_level, 1)
        notification_priority = level_priority.get(level, 1)

        return notification_priority >= current_priority

    def _add_to_buffer(self, notification: Dict[str, Any]):
        """添加到通知缓冲区"""
        with self.buffer_lock:
            self.notification_buffer.append(notification)

            # 检查缓冲区大小
            if len(self.notification_buffer) > self.buffer_size:
                self.notification_buffer.pop(0)
                self.stats['buffer_overflows'] += 1

    def _notify_subscribers(self, notification_type: NotificationType, notification: Dict[str, Any]):
        """通知订阅者"""
        if notification_type in self.subscribers:
            for callback in self.subscribers[notification_type]:
                try:
                    callback(notification)
                    self.stats['successful_notifications'] += 1
                except Exception as e:
                    self.stats['failed_notifications'] += 1
                    print(f"通知回调执行失败: {e}")

    def start_buffering(self):
        """启动缓冲处理"""
        if not self.buffering:
            self.buffering = True
            self.buffer_thread = threading.Thread(target=self._buffer_processor, daemon=True)
            self.buffer_thread.start()

    def stop_buffering(self):
        """停止缓冲处理"""
        self.buffering = False
        if self.buffer_thread:
            self.buffer_thread.join(timeout=5)
            self.buffer_thread = None

    def _buffer_processor(self):
        """缓冲处理器"""
        while self.buffering:
            try:
                notifications = self._get_buffered_notifications()
                if notifications:
                    self._process_buffered_notifications(notifications)

                time.sleep(self.buffer_timeout)

            except Exception as e:
                print(f"缓冲处理器错误: {e}")
                time.sleep(self.buffer_timeout)

    def _get_buffered_notifications(self) -> List[Dict[str, Any]]:
        """获取缓冲的通知"""
        with self.buffer_lock:
            notifications = self.notification_buffer.copy()
            self.notification_buffer.clear()
            return notifications

    def _process_buffered_notifications(self, notifications: List[Dict[str, Any]]):
        """处理缓冲的通知"""
        # 按通道分组
        channel_groups = {}
        for notification in notifications:
            for channel in notification['channels']:
                if channel not in channel_groups:
                    channel_groups[channel] = []
                channel_groups[channel].append(notification)

        # 发送到各个通道
        for channel, channel_notifications in channel_groups.items():
            self._send_to_channel(channel, channel_notifications)

    def _send_to_channel(self, channel: str, notifications: List[Dict[str, Any]]):
        """发送通知到指定通道"""
        try:
            if channel == 'console':
                self._send_to_console(notifications)
            elif channel == 'file':
                self._send_to_file(notifications)
            elif channel == 'email':
                self._send_to_email(notifications)
            elif channel == 'webhook':
                self._send_to_webhook(notifications)
            else:
                print(f"未知的通知通道: {channel}")

        except Exception as e:
            print(f"发送通知到通道 {channel} 失败: {e}")

    def _send_to_console(self, notifications: List[Dict[str, Any]]):
        """发送到控制台"""
        for notification in notifications:
            if self.format_type == 'json':
                print(json.dumps(notification, ensure_ascii=False, indent=2))
            else:
                print(f"[{notification['timestamp']}] {notification['type']}: {notification['data']}")

    def _send_to_file(self, notifications: List[Dict[str, Any]]):
        """发送到文件"""
        log_file = self.config.get('log_file', 'config_notifications.log')

        try:
            with open(log_file, 'a', encoding='utf-8') as f:
                for notification in notifications:
                    if self.format_type == 'json':
                        f.write(json.dumps(notification, ensure_ascii=False) + '\n')
                    else:
                        f.write(f"[{notification['timestamp']}] {notification['type']}: {notification['data']}\n")
        except Exception as e:
            print(f"写入通知文件失败: {e}")

    def _send_to_email(self, notifications: List[Dict[str, Any]]):
        """发送到邮件"""
        # 实现邮件发送逻辑
        pass

    def _send_to_webhook(self, notifications: List[Dict[str, Any]]):
        """发送到Webhook"""
        webhook_url = self.config.get('webhook_url')
        if not webhook_url:
            return

        try:
            import requests

            payload = {
                'notifications': notifications,
                'timestamp': datetime.now().isoformat()
            }

            response = requests.post(webhook_url, json=payload, timeout=10)
            response.raise_for_status()

        except Exception as e:
            print(f"发送Webhook通知失败: {e}")

    def get_notification_history(self, limit: int = 100) -> List[Dict[str, Any]]:
        """获取通知历史"""
        with self.buffer_lock:
            return self.notification_buffer[-limit:]

    def clear_notification_history(self):
        """清除通知历史"""
        with self.buffer_lock:
            self.notification_buffer.clear()

    def get_stats(self) -> Dict[str, Any]:
        """获取统计信息"""
        return {
            **self.stats,
            'subscriber_count': sum(len(callbacks) for callbacks in self.subscribers.values()),
            'buffer_size': len(self.notification_buffer),
            'buffering': self.buffering
        }
```

```python

from config_management.utils.config_watcher import ConfigWatcher
```

```python
class ConfigManager:
    """完整的配置管理器"""

    def __init__(self, config: dict):
        self.config = config

        # 初始化各个组件
        self.storage = FileConfigStorage(config.get('storage', {}))
        self.watcher = ConfigWatcher(config.get('watcher', {}))
        self.reloader = ConfigReloader(config.get('reloader', {}))
        self.notifier = ConfigNotifier(config.get('notifier', {}))
        self.encryption = ConfigEncryption(config.get('encryption', {}))
        self.access_control = ConfigAccessControl(config.get('access_control', {}))

        # 设置回调
        self._setup_callbacks()

    def _setup_callbacks(self):
        """设置回调函数"""
        def on_config_change(file_path, event_type):
            self.notifier.notify(NotificationType.CONFIG_CHANGED, {
                'file_path': file_path,
                'event_type': event_type
            })

        def on_config_reload(old_config, new_config):
            self.notifier.notify(NotificationType.CONFIG_RELOADED, {
                'changes': len(new_config) - len(old_config)
            })

        self.watcher.add_callback(on_config_change)
        self.reloader.add_reload_callback(on_config_reload)

    def start(self):
        """启动配置管理服务"""
        self.watcher.start_watching()
        self.reloader.start_auto_reload()
        self.notifier.start_buffering()
        print("配置管理服务已启动")

    def stop(self):
        """停止配置管理服务"""
        self.watcher.stop_watching()
        self.reloader.stop_auto_reload()
        self.notifier.stop_buffering()
        print("配置管理服务已停止")

    def get_config(self, key: str, user: str = None, default=None):
        """获取配置（带权限检查）"""
        if user and not self.access_control.check_permission(user, key, 'read'):

        return self.storage.get_config(key, default)

        if user and not self.access_control.check_permission(user, key, 'write'):
            raise PermissionError(f"用户 {user} 没有写入配置 {key} 的权限")

        if encrypt:
            value = self.encryption.encrypt(value)

        return self.storage.set_config(key, value)

    def get_stats(self):
        """获取统计信息"""
        return {
            'storage': self.storage.get_stats(),
            'watcher': self.watcher.get_watch_status(),
            'reloader': self.reloader.get_stats(),
            'notifier': self.notifier.get_stats()
        }
```

```python
# 使用文件锁
class SafeConfigStorage(FileConfigStorage):

        super().__init__(config)
        self._file_lock = threading.Lock()

    def _set_config_value(self, key: str, value: Any) -> bool:
        with self._file_lock:
            # 重试机制
            max_retries = 3
            for attempt in range(max_retries):
                try:
                    return super()._set_config_value(key, value)
                except Exception as e:
                    if attempt == max_retries - 1:
                        raise
                    time.sleep(0.1 * (attempt + 1))  # 指数退避
            return False

# 使用安全配置存储
safe_storage = SafeConfigStorage({
    'config_file': 'app_config.json',
    'format': 'json'
})
```

### 9.3 配置安全问题

#### 9.3.1 敏感配置泄露

```python
    if value and not value.startswith('encrypted:'):
        encrypted_value = encryption.encrypt(value)
        config_storage.set_config(key, f'encrypted:{encrypted_value}')

# 获取配置时自动解密
def get_safe_config(key, default=None):
    value = config_storage.get_config(key, default)
    if isinstance(value, str) and value.startswith('encrypted:'):
```

### 9.4 配置性能问题

#### 9.4.1 配置加载速度慢

**问题**: 配置文件过大或加载频繁导致性能问题

**解决方案**:

```python
from config_management.utils.config_loader import ConfigLoader

# 启用缓存
loader = ConfigLoader({
    'cache_enabled': True,
    'cache_ttl': 300  # 5分钟缓存
})

# 使用配置缓存
class CachedConfigManager:
    def __init__(self, config_file):
        self.config_file = config_file
        self._cache = {}
        self._cache_time = {}
        self._cache_ttl = 300  # 5分钟

    def get_config(self, key, default=None):
        # 检查缓存
        if key in self._cache:
            if time.time() - self._cache_time[key] < self._cache_ttl:
                return self._cache[key]

        # 从文件加载
        config_data = loader.load_config(self.config_file)
        value = config_data.get(key, default)

        # 更新缓存
        self._cache[key] = value
        self._cache_time[key] = time.time()

        return value

    def clear_cache(self):
        self._cache.clear()
        self._cache_time.clear()

# 使用缓存配置管理器
cached_manager = CachedConfigManager('./config/app.json')
```

#### 9.4.2 配置监听性能问题

**问题**: 配置监听器占用过多系统资源

**解决方案**:

```python
from config_management.utils.config_watcher import ConfigWatcher

# 优化监听器配置
optimized_watcher = ConfigWatcher({
    'watch_paths': ['./config'],  # 只监听必要路径
    'watch_recursive': False,     # 不递归监听
    'debounce_time': 2.0,        # 增加防抖时间
    'file_extensions': ['.json']  # 只监听特定文件类型
})

# 使用批量处理
class BatchConfigWatcher(ConfigWatcher):
    def __init__(self, config):
        super().__init__(config)
        self._pending_changes = set()
        self._batch_timer = None
        self._batch_delay = 5.0  # 5秒批量处理

    def _handle_file_change(self, file_path, event_type):
        self._pending_changes.add((file_path, event_type))

        # 重置定时器
        if self._batch_timer:
            self._batch_timer.cancel()

        self._batch_timer = threading.Timer(self._batch_delay, self._process_batch)
        self._batch_timer.start()

    def _process_batch(self):
        if self._pending_changes:
            print(f"批量处理 {len(self._pending_changes)} 个文件变更")
            for file_path, event_type in self._pending_changes:
                for callback in self.callbacks:
                    try:
                        callback(file_path, event_type)
                    except Exception as e:
                        print(f"回调执行失败: {e}")
            self._pending_changes.clear()
```
