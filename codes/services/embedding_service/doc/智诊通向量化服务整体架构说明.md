# 智诊通向量化服务整体架构说明

## 📋 服务概述

智诊通向量化服务是智诊通 RAG（检索增强生成）系统的核心组件，负责将医疗领域的多模态数据（文本、图像、语音）转换为高维向量表示，为智能检索和问答系统提供语义理解基础。

## 🔄 数据流程

### 1. 文本向量化流程

```
📝 文本输入
    ↓
🔧 文本预处理 (清洗、标准化、分词)
    ↓
✂️ 文档切分 (医疗结构化切分策略)
    ↓
🧠 文本嵌入 (BiomedCLIP文本模型)
    ↓
📊 质量检查 (完整性、唯一性、相关性)
    ↓
💾 向量存储 (ChromaDB)
    ↓
📤 结果返回 (向量 + 元数据)
```

### 2. 图像向量化流程

```
🖼️ 图像输入
    ↓
🔧 图像预处理 (尺寸调整、格式转换、归一化)
    ↓
🧠 图像嵌入 (BiomedCLIP视觉模型)
    ↓
📊 质量检查 (图像质量、内容相关性)
    ↓
💾 向量存储 (ChromaDB)
    ↓
📤 结果返回 (向量 + 元数据)
```

### 3. 语音向量化流程

```
🎵 语音输入
    ↓
🔧 语音预处理 (采样率调整、格式转换)
    ↓
🗣️ 语音转文本 (Whisper模型)
    ↓
🧠 文本嵌入 (BiomedCLIP文本模型)
    ↓
📊 质量检查 (转录质量、内容相关性)
    ↓
💾 向量存储 (ChromaDB)
    ↓
📤 结果返回 (向量 + 元数据)
```

### 4. 跨模态检索流程

```
🔍 查询输入 (文本/图像/语音)
    ↓
🧠 查询向量化 (对应模态嵌入器)
    ↓
🔎 相似度计算 (余弦相似度)
    ↓
📊 结果排序 (按相似度分数)
    ↓
🎯 质量过滤 (相关性阈值)
    ↓
📤 结果返回 (Top-K结果)
```

## 🔧 技术栈

### 核心技术

- **Python 3.8+**: 主要开发语言
- **FastAPI**: Web 框架和 API 服务
- **PyTorch**: 深度学习框架
- **Transformers**: 预训练模型库
- **ChromaDB**: 向量数据库
- **NumPy**: 数值计算
- **Pillow**: 图像处理
- **Librosa**: 音频处理

### 主要模型

- **BiomedCLIP**: 医疗领域多模态模型
- **Whisper**: 语音转文本模型
- **Sentence-Transformers**: 语义相似度模型
- **DistilBERT**: 文本分类模型

## 🚀 快速开始

### 1. 环境准备

```bash
# 安装依赖
pip install -r requirements.txt

# 下载预训练模型
python download_models.py

# 配置环境变量
export EMBEDDING_SERVICE_CONFIG_PATH=/path/to/config
```

> 📖 **详细说明**：环境配置、依赖管理、模型下载等详细信息，请参考 [配置管理详细说明文档](./智诊通向量化服务配置管理详细说明.md)

### 2. 启动服务

```bash
# 启动向量化服务
cd codes/services/embedding_service
python start_embedding_service.py

# 服务将在 http://localhost:8001 启动
```

> 📖 **详细说明**：服务启动流程、Docker 部署、监控运维等详细信息，请参考 [部署运维指南文档](./智诊通向量化服务部署运维指南.md)

### 3. 使用示例

```python
# 导入服务客户端
from api.embedding_service_client import EmbeddingServiceClient

# 创建客户端
client = EmbeddingServiceClient("http://localhost:8001")

# 文本向量化
texts = ["患者主诉胸痛", "心电图显示异常"]
result = client.vectorize_text(texts)
print(f"文本向量维度: {result['vectors'].shape}")

# 图像向量化
image_paths = ["chest_xray.jpg", "ecg.png"]
result = client.vectorize_images(image_paths)
print(f"图像向量维度: {result['vectors'].shape}")

# 跨模态检索
query = "心脏疾病"
results = client.cross_modal_retrieve(query, "text", top_k=5)
for result in results:
    print(f"相似度: {result['score']}, 内容: {result['content']}")
```
