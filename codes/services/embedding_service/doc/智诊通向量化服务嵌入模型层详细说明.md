# 智诊通向量化服务嵌入模型层详细说明

## 📋 模块概述

嵌入模型层是智诊通向量化服务的核心组件，负责将不同模态的数据（文本、图像）转换为高维向量表示。该层使用统一的 BiomedCLIP 模型确保不同模态数据在相同的向量空间中进行处理，为跨模态检索提供基础支持。

### 🎯 核心功能

- **文本向量化**: 将医疗文本转换为 512 维向量
- **图像向量化**: 将医学图像转换为 512 维向量
- **统一向量空间**: 确保文本和图像向量在同一空间
- **批量处理**: 支持批量数据的高效处理
- **模型管理**: 统一的模型加载和管理
- **设备优化**: 支持 CPU 和 GPU 设备

#### 1.5 核心方法详解

##### 1.5.1 文本向量化方法

```python
def embed_texts(self, texts: List[str]) -> np.ndarray:
    """
    对文本列表进行向量化

    Args:
        texts: 文本列表

    Returns:
        向量数组
    """
    if not texts:
        return np.array([])

    # 批量处理
    embeddings = []
    batch_size = 32

    for i in range(0, len(texts), batch_size):
        batch_texts = texts[i:i + batch_size]
        batch_embeddings = self._embed_batch(batch_texts)
        embeddings.extend(batch_embeddings)

    return np.array(embeddings)
```

**处理流程**:

1. 输入验证
2. 批量处理
3. 向量化计算
4. 结果合并

##### 1.5.3 批量处理优化

```python
def _embed_batch(self, texts: List[str]) -> List[np.ndarray]:
    """
    批量处理文本向量化

    Args:
        texts: 文本批次

    Returns:
        向量列表
    """
    try:
        # 文本预处理
        processed_texts = [self._preprocess_text(text) for text in texts]

        # 分词处理
        inputs = self.tokenizer(
            processed_texts,
            padding=True,
            truncation=True,
            max_length=512,
            return_tensors="pt"
        )

        # 移动到设备
        inputs = {k: v.to(self.device) for k, v in inputs.items()}

        # 模型推理
        with torch.no_grad():
            outputs = self.model(**inputs)
            embeddings = outputs.last_hidden_state.mean(dim=1)

        # 转换为numpy数组
        return embeddings.cpu().numpy()

    except Exception as e:
        logger.error(f"批量处理失败: {e}")
        raise
```

**优化特性**:

- 批量处理提高效率
- 动态填充和截断
- GPU 加速支持
- 内存优化

#### 1.6 文本预处理

##### 1.6.1 文本预处理方法

```python
def _preprocess_text(self, text: str) -> str:
    """
    文本预处理

    Args:
        text: 原始文本

    Returns:
        预处理后的文本
    """
    if not text:
        return ""

    # 去除多余空白
    text = " ".join(text.split())

    # 去除特殊字符
    text = text.strip()

    # 长度限制
    if len(text) > 1000:
        text = text[:1000]

    return text
```

**预处理步骤**:

1. 空白字符处理
2. 特殊字符清理
3. 长度限制
4. 格式标准化

def embed_images(self, image_paths: List[str]) -> np.ndarray:

##### 2.5.3 批量处理优化

```python
def _embed_batch(self, image_paths: List[str]) -> List[np.ndarray]:
    """
    批量处理图像向量化

    Args:
        image_paths: 图像路径批次

    Returns:
        向量列表
    """
    try:
        # 加载和预处理图像
        images = []
        for path in image_paths:
            try:
                image = self._load_and_preprocess_image(path)
                images.append(image)
            except Exception as e:
                logger.warning(f"图像加载失败 {path}: {e}")
                # 使用零向量作为占位符
                images.append(torch.zeros(3, 224, 224))

        # 转换为批次张量
        batch_tensor = torch.stack(images).to(self.device)

        # 模型推理
        with torch.no_grad():
            embeddings = self.model.encode_image(batch_tensor)

        # 转换为numpy数组
        return embeddings.cpu().numpy()

    except Exception as e:
        logger.error(f"批量处理失败: {e}")
        raise
```

**优化特性**:

- 批量处理提高效率
- 错误处理和占位符
- GPU 加速支持
- 内存优化
