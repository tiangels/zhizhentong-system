# 智诊通向量化服务核心服务层详细说明

## 📋 模块概述

核心服务层是智诊通向量化服务的中枢，负责协调各个功能模块，提供统一的向量化服务接口。该层整合了文本、图像、语音等多种模态的向量化功能，实现了跨模态检索和统一的数据处理流程。

### 🎯 核心功能

- **统一向量化接口**: 提供文本、图像、语音的统一向量化服务
- **跨模态检索**: 实现不同模态数据间的语义检索
- **多模态数据库构建**: 构建统一的多模态向量数据库
- **服务协调**: 协调各个功能模块的工作
- **配置管理**: 统一管理服务配置和参数
- **性能监控**: 监控服务性能和资源使用

##### 2.3.3 相似度计算

```python
def calculate_similarity(self, vector1: np.ndarray, vector2: np.ndarray) -> float:
    """
    计算两个向量的相似度

    Args:
        vector1: 向量1
        vector2: 向量2

    Returns:
        相似度分数
    """
    # 使用余弦相似度
    dot_product = np.dot(vector1, vector2)
    norm1 = np.linalg.norm(vector1)
    norm2 = np.linalg.norm(vector2)

    if norm1 == 0 or norm2 == 0:
        return 0.0

    return dot_product / (norm1 * norm2)
```

```python
def _get_memory_usage(self) -> str:
    """获取内存使用情况"""
    import psutil
    process = psutil.Process()
    memory_info = process.memory_info()
    return f"{memory_info.rss / 1024 / 1024:.1f}MB"

def _get_cpu_usage(self) -> str:
    """获取CPU使用情况"""
    import psutil
    cpu_percent = psutil.cpu_percent(interval=1)
    return f"{cpu_percent:.1f}%"
```
