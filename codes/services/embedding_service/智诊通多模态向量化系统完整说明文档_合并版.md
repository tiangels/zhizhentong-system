# 智诊通多模态向量化系统完整说明文档

## 📋 系统概述

智诊通多模态向量化系统是一个基于 RAG（Retrieval-Augmented Generation）技术的智能医疗知识检索平台，支持文本、图像、语音等多种模态的医疗数据处理和检索。系统采用先进的向量化技术，结合大语言模型，为医疗领域提供准确、高效的智能问答服务。

### 🎯 核心特性

- **多模态支持**：文本、图像、语音数据的统一处理
- **跨模态检索**：图像查询返回相关文本，文本查询支持图像结果
- **智能向量化**：基于预训练模型的语义向量表示
- **医疗分词优化**：专门针对医疗领域的中文分词优化 ⭐
- **术语保护机制**：防止医疗术语被错误切分 ⭐
- **NER 集成**：医疗命名实体识别和混合分词策略 ⭐
- **BiomedCLIP 优化**：中英混合文本预处理，提升中文支持 ⭐
- **高效检索**：基于向量相似度的快速检索
- **生产就绪**：完整的部署配置和监控体系
- **稳定可靠**：已解决向量化过程中断问题，支持小样本测试模式
- **质量保证**：集成专业质量检查器，确保数据质量
- **配置驱动**：支持通过配置文件灵活替换模型
- **分离式架构**：清晰的职责分离，便于维护和扩展

### 1. 知识库构建流程

```
原始数据 → 数据预处理 → 文档加载 → 数据清洗 → 文档切分 → 质量检查 → 向量化 → 索引构建
   ↓         ↓         ↓         ↓         ↓         ↓         ↓         ↓
Word/PDF  格式转换   多格式    去重/过滤   Chunk    四层检查   向量表示   向量数据库
TXT/Excel 内容提取   支持      标准化     切分      质量评估   生成      ChromaDB
图像文件   OCR识别   结构化    敏感信息   语义切分   过滤优化   嵌入向量   索引构建
音频文件  语音识别   输出      处理       智能切分   质量保证   多维向量   存储优化
```

**详细流程说明**：

1. **数据预处理阶段**：

   - 文本数据：PDF/Word → 文本提取 → 内容清洗 → JSON 结构化
   - 图文数据：X 光片/CT → OCR 识别 → 文本提取 → 脱敏处理 → JSON 结构化
   - 语音数据：音频文件 → 语音识别 → 文本转换 → 内容清洗 → JSON 结构化

2. **文档处理阶段**：

   - 文档加载：支持多种格式的统一加载
   - 数据清洗：去重、标准化、缺失值处理
   - 文档切分：智能切分策略，保持语义完整性

3. **质量检查阶段**：

   - 完整性检查：过滤空白、长度异常的文本片段
   - 唯一性检查：基于哈希和语义相似度的去重
   - 相关性检查：过滤无关关键词，确保医疗内容
   - 向量化前置检查：确保文本适合向量化

4. **分词优化阶段**：

   - 医疗术语识别：使用增强的 jieba 分词器
   - 术语保护：防止医疗术语被错误切分
   - NER 集成：医疗命名实体识别
   - 混合分词：结合多种分词策略

5. **向量化阶段**：
   - 向量化：多模态向量表示生成
   - 索引构建：高效检索索引构建

#### 1.6 医疗术语处理 (Medical Terminology Processing) ⭐

**医疗术语处理是智诊通系统的核心特色，专门针对医疗领域的中文分词优化。**

##### 1.6.1 当前分词实现分析

**jieba 分词器局限性**:

- 基于通用语料训练，医疗专业术语覆盖率低
- 无法识别复合医学术语，如"冠状动脉粥样硬化性心脏病"
- 对医疗缩写和同义词处理不佳

**BiomedCLIP 分词器局限性**:

- 基于 PubMedBERT，主要针对英文优化
- 对中文医疗文本的分词效果不佳
- 无法处理中文特有的语言结构

##### 1.6.2 分词优化方案

```python
def enhance_jieba_medical_dict():

    medical_terms = [

        # 药物
        '阿司匹林', '硝酸甘油', '美托洛尔', '二甲双胍'
    ]

    for term in medical_terms:
        jieba.add_word(term, freq=1000, tag='medical')

def protect_medical_terms(text: str) -> str:
    """保护医疗术语不被切分"""
    medical_terms = [
        '冠状动脉粥样硬化性心脏病', '急性心肌梗死', '慢性心力衰竭'
    ]

    protected_text = text
    for i, term in enumerate(medical_terms):
        if term in protected_text:
            placeholder = f"__MEDICAL_{i}__"
            protected_text = protected_text.replace(term, placeholder)

    return protected_text
```

```python
    def tokenize(self, text: str) -> List[str]:

        # 1. 使用NER识别医疗实体
        medical_entities = self._extract_medical_entities(text)

        # 2. 保护医疗实体不被切分
        protected_text = self._protect_entities(text, medical_entities)

        tokens = list(self.jieba_tokenizer.cut(protected_text))

        # 4. 后处理：合并被错误切分的医疗术语

        return tokens
```

#### 2.1 跨模态检索实现原理

**核心问题**：对于图文数据集，每张图片都有对应的文本说明，当用户输入一张图片时，如何通过检索找到相似图片对应的文本返回给用户？

**解决方案**：

1. **图像-文本映射关系构建**

```python
def build_image_text_mapping(self, reports_df: pd.DataFrame) -> Dict[str, Dict[str, Any]]:
    """构建图像和文本的映射关系"""
    mapping = {}

    for idx, row in reports_df.iterrows():
        uid = str(row['uid'])

        # 构建文本内容
        text_parts = []
        if 'findings' in row and pd.notna(row['findings']):
            text_parts.append(f"检查结果: {row['findings']}")
        if 'impression' in row and pd.notna(row['impression']):
            text_parts.append(f"印象: {row['impression']}")

        if text_parts:
            text_content = "\n".join(text_parts)
            mapping[uid] = {
                'text': text_content,
                'index': idx,
                'metadata': {...}
            }

    return mapping
```

2. **双向量存储策略**

**策略 A：图像向量存储（推荐）**

- 图像向量化：使用 ResNet50/CLIP 等模型将图像转换为向量
- 存储方式：图像向量存储在向量数据库中
- 检索过程：
  1. 用户输入图像 → 向量化 → 在图像向量库中搜索
  2. 找到相似图像 → 通过映射关系获取对应文本

**策略 B：文本向量存储（备选）**

- 文本向量化：使用文本嵌入模型将描述文本转换为向量
- 存储方式：文本向量存储在向量数据库中

3. **跨模态检索系统实现**

**核心类**：`CrossModalRetrieval`（位于 `core/cross_modal_retrieval.py`）

**主要功能**：

- `search()`: 统一的跨模态检索接口
- `text_to_image_search()`: 文本到图像检索
- `image_to_text_search()`: 图像到文本检索
- `get_image_text_pairs()`: 获取图像文本对

**使用方法**：

```python
from core.cross_modal_retrieval import CrossModalRetrieval

# 初始化检索系统

# 文本检索

```

- 检索过程：
  1. 用户输入图像 → 向量化 → 在文本向量库中搜索
  2. 找到相似文本 → 直接返回文本内容

3. **跨模态检索流程**

```python
def search_by_image(self, image_path: str, top_k: int = 5) -> List[RetrievalResult]:
    """通过图像查询检索相关内容"""
    try:
        # 1. 对输入图像进行向量化
        image_vector = self.image_embedder.embed_image(processed_image)

        # 2. 在图像向量数据库中搜索
        image_results = self.image_vector_db._collection.query(
            query_embeddings=[image_vector.tolist()],
            n_results=top_k
        )

        # 3. 通过映射关系获取对应文本
        results = []
        if image_results['ids'] and len(image_results['ids'][0]) > 0:
            for i, (doc_id, distance) in enumerate(zip(image_results['ids'][0], image_results['distances'][0])):
                # 从doc_id中提取索引
                index = int(doc_id.split('_')[-1])

                # 通过映射关系获取文本
                if str(index) in self.image_text_mapping:
                    mapping_info = self.image_text_mapping[str(index)]
                    result = RetrievalResult(
                        content=mapping_info['text'],
                        score=1.0 - distance,
                        metadata=mapping_info['metadata']
                    )
                    results.append(result)

        return results
    except Exception as e:
        logger.error(f"图像检索失败: {e}")
        return []
```

## 🔍 质量检查功能详解

### 质量检查系统架构

智诊通系统集成了完整的质量检查功能，采用**四层检查机制**，确保只有高质量的数据进入向量化流程：

```
原始数据 → 文档切分 → 质量检查 → 向量化 → 数据库存储
                ↓
        四层质量检查机制
```

### 四层质量检查机制

#### 第一层：完整性检查 (Completeness Check)

- **功能**：过滤空白、长度异常的文本片段
- **检查项目**：
  - 剔除纯空白文本（strip()后长度为 0）
  - 过滤仅含标点符号的文本
  - 过滤过短片段（默认<10 字符，可配置）
  - 过滤过长片段（超过模型 Token 上限的 1.2 倍）
- **实现位置**：`analyzer/quality_analyzer.py` 的 `check_completeness()` 方法

#### 第二层：唯一性检查 (Uniqueness Check)

- **功能**：剔除重复文本，避免向量库冗余
- **检查项目**：
  - 基于 MD5 哈希的精确去重
  - 基于语义相似度的去重（使用 Sentence-BERT）
  - 相似度阈值可配置（默认>0.95 判定为重复）
- **实现位置**：`analyzer/quality_analyzer.py` 的 `check_uniqueness()` 方法

#### 第三层：相关性检查 (Relevance Check)

- **功能**：过滤与业务无关的"噪声文本"
- **检查项目**：
  - 关键词过滤（可配置无关关键词列表）
  - 医疗内容检测（确保包含医疗相关关键词）
  - 乱码/低质量文本过滤（检查特殊字符占比）
  - 语义分类（使用轻量级 DistilBERT 模型）
- **实现位置**：`analyzer/quality_analyzer.py` 的 `check_relevance()` 方法

#### 第四层：向量化前置检查 (Vectorization Readiness Check)

- **功能**：确保文本可正常转换为向量
- **检查项目**：
  - 文本编码检查（统一为 UTF-8）
  - 编码检测（使用 chardet 库，可选）
  - 预计算 Token 数量（使用向量化模型的 tokenizer）
  - 模型兼容性检查
- **实现位置**：`analyzer/quality_analyzer.py` 的 `check_vectorization_readiness()` 方法

### 质量检查集成点

质量检查器在向量化流程中的**三个关键集成点**：

#### 集成点 1：文档切分后检查

在 `prepare_general_text_documents()` 方法中，对每个文档片段进行四层质量检查：

## 🔧 核心功能实现

### 1. 数据预处理服务 ⭐

**数据预处理是系统的核心基础，负责将原始医疗数据转换为标准化的结构化数据。**

#### 1.1 文本数据预处理

**实现位置**：`processors/text_preprocessing.py`
**核心类**：`BaseProcessor`

**功能特性**：

- **多格式支持**：Word、PDF、TXT、Excel、JSON
- **智能识别**：自动检测文档类型和编码
- **内容提取**：提取文本内容、元数据、页面信息
- **数据清洗**：去除重复、标准化格式、处理缺失值
- **敏感信息处理**：自动识别和脱敏处理医疗敏感信息
- **质量评估**：计算文档质量分数和医学术语统计

**使用示例**：

```python
from processors.text_preprocessing import BaseProcessor

# 创建文本预处理器
processor = BaseProcessor(
    raw_data_dir="datas/medical_knowledge/text_data/raw",
    output_dir="datas/medical_knowledge/text_data/processed"
)

# 运行文本预处理
processor.run(sample_size=10, process_all_files=True)
```

#### 1.2 图文数据预处理

**实现位置**：`processors/image_text_preprocessing.py`
**核心类**：`MedicalImageTextPreprocessor`

**功能特性**：

- **图像处理**：支持 X 光片、CT、MRI、病理图像等多种医学影像
- **OCR 识别**：基于先进 OCR 技术提取图像中的文本信息
- **内容清洗**：去除噪声、标准化医学术语、处理特殊符号
- **敏感信息处理**：自动识别和脱敏处理患者信息
- **质量评估**：评估图像质量和文本提取准确性

**使用示例**：

```python
from processors.image_text_preprocessing import MedicalImageTextPreprocessor

# 创建图文预处理器
processor = MedicalImageTextPreprocessor(
    raw_data_dir="datas/medical_knowledge/image_text_data/raw",
    output_dir="datas/medical_knowledge/image_text_data/processed"
)

# 运行图文预处理
processor.run(sample_size=10, process_all_files=True)
```

#### 1.3 语音数据预处理

**实现位置**：`processors/voice_preprocessing.py`
**核心类**：`VoicePreprocessor`

**功能特性**：

- **多格式支持**：WAV、MP3、M4A、FLAC、AAC、OGG 等音频格式
- **语音识别**：基于 Whisper 模型的高精度语音转文本
- **语言检测**：自动识别语音语言类型
- **内容清洗**：去除语音识别错误、标准化医疗术语
- **质量评估**：评估语音质量和识别准确性

**使用示例**：

```python
from processors.voice_preprocessing import VoicePreprocessor

# 创建语音预处理器
processor = VoicePreprocessor(
    raw_data_dir="datas/medical_knowledge/voice_data/raw",
    output_dir="datas/medical_knowledge/voice_data/processed"
)

# 运行语音预处理
processor.run(sample_size=5, process_all_files=True)
```

### 1. BiomedCLIP 技术架构

**模型组成**：

- **视觉编码器**：ViT-Base-Patch16-224 (512 维)
- **文本编码器**：PubMedBERT (768 维)
- **投影层**：将视觉和文本特征投影到共同空间 (256 维)

**分词器分析**：

```python
# BiomedCLIP分词器实现
def _load_openclip_model(self, model_path: str):
    # 使用PubMedBERT分词器
    self.tokenizer = open_clip.get_tokenizer('hf-hub:microsoft/BiomedCLIP-PubMedBERT_256-vit_base_patch16_224')
```

### 2. 中文支持局限性

**主要问题**：

- PubMedBERT 主要基于英文 PubMed 语料训练
- 对中文医疗文本的分词效果不佳
- 无法处理中文特有的语言结构
- 中文医疗术语的语义表示可能不准确

### 3. 优化策略

**策略一：中英混合文本预处理**

```python
class BiomedCLIPChineseOptimizer:
    """BiomedCLIP中文优化器"""

    def preprocess_chinese_text(self, text: str) -> str:
        """中文医疗文本预处理"""
        # 1. 医疗术语标准化
        standardized_text = self._standardize_medical_terms(text)

        # 2. 关键医疗术语翻译为英文
        mixed_text = self._translate_key_terms(standardized_text)

        # 3. 保持中英文混合格式
        return mixed_text
```

**策略二：增强分词器集成**

```python
def integrate_enhanced_tokenizer():
    """集成增强分词器"""
    # 1. 使用增强的jieba分词器
    enhanced_jieba = MedicalChineseTokenizer()

    # 2. 预处理中文文本
    processed_text = enhanced_jieba.tokenize(chinese_text)

    # 3. 转换为BiomedCLIP可理解的格式
```
