# 质量分析器模型使用说明

## 📋 概述

质量分析器（QualityAnalyzer）使用两个外部模型来提升医疗数据质量检查的准确性：

1. **语义相似度模型** (`paraphrase-multilingual-MiniLM-L12-v2`)
2. **文本分类模型** (`distilbert-base-multilingual-cased`)

## 🤖 模型详细说明

### 1. 语义相似度模型 - paraphrase-multilingual-MiniLM-L12-v2

#### **作用**

- **语义去重**: 检测语义相似但字面不同的文本
- **相似度计算**: 计算文本之间的语义相似度分数
- **多语言支持**: 支持中文、英文等多种语言

#### **使用场景**

```python
# 在 check_uniqueness 方法中使用
embeddings = self.sentence_model.encode(valid_texts, batch_size=self.config['batch_size'])
similarity_matrix = cosine_similarity(embeddings)
```

#### **工作原理**

1. 将文本转换为高维向量表示
2. 计算向量间的余弦相似度
3. 识别相似度超过阈值的文本对
4. 标记为重复内容

### 2. 文本分类模型 - distilbert-base-multilingual-cased

#### **作用**

- **相关性判断**: 判断文本是否与医疗领域相关
- **内容过滤**: 过滤掉无关的文本内容
- **质量提升**: 确保数据质量符合医疗标准

#### **使用场景**

```python
# 在 check_relevance 方法中使用
inputs = self.classifier_tokenizer(text, return_tensors="pt", truncation=True, max_length=512)
outputs = self.classifier_model(**inputs)
predictions = torch.nn.functional.softmax(outputs.logits, dim=-1)
relevance_score = predictions[0][1].item()
```

#### **工作原理**

1. 将文本分词并转换为模型输入格式
2. 通过预训练的 DistilBERT 模型进行分类
3. 输出相关性概率分数
4. 根据阈值判断是否通过检查

## 🔌 模型连接方式

### 自动下载机制

这两个模型都通过 **Hugging Face Hub** 自动下载：

```python
# 语义相似度模型
self.sentence_model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')

# 文本分类模型
self.classifier_tokenizer = AutoTokenizer.from_pretrained('distilbert-base-multilingual-cased')
self.classifier_model = AutoModelForSequenceClassification.from_pretrained(
    'distilbert-base-multilingual-cased', num_labels=2
)
```

### 模型存储位置

模型会自动下载到以下位置：

- **macOS/Linux**: `~/.cache/huggingface/hub/`
- **Windows**: `C:\Users\{username}\.cache\huggingface\hub\`

### 首次运行流程

1. **检查依赖**: 系统检查是否安装了必要的库
2. **自动下载**: 首次使用时自动从 Hugging Face 下载模型
3. **缓存存储**: 下载的模型缓存在本地，后续使用无需重新下载
4. **延迟加载**: 只有在实际需要时才加载模型，节省内存

## ⚙️ 配置选项

### 在 unified_config.json 中配置

```json
{
  "quality_analyzer": {
    "semantic_model_name": "paraphrase-multilingual-MiniLM-L12-v2",
    "classifier_model_name": "distilbert-base-multilingual-cased",
    "similarity_threshold": 0.85,
    "relevance_threshold": 0.5
  }
}
```

### 自定义模型

```python
# 使用自定义模型
custom_config = {
    'semantic_model_name': 'your-custom-semantic-model',
    'classifier_model_name': 'your-custom-classifier-model'
}
analyzer = QualityAnalyzer("data_dir", custom_config)
```

## 🚀 使用示例

### 基本使用

```python
from quality_analyzer import QualityAnalyzer

# 使用默认配置（自动下载模型）
analyzer = QualityAnalyzer("your_data_directory")

# 执行质量检查
results = analyzer.analyze_texts(["文本1", "文本2", "文本3"])
```

### 自定义配置

```python
# 使用自定义配置
config = {
    'semantic_model_name': 'paraphrase-multilingual-MiniLM-L12-v2',
    'classifier_model_name': 'distilbert-base-multilingual-cased',
    'similarity_threshold': 0.8,
    'relevance_threshold': 0.6

```

## 📊 性能优化

### 1. 模型缓存

- 模型首次下载后会缓存在本地
- 后续使用无需重新下载
- 可以通过 `~/.cache/huggingface/hub/` 管理缓存

### 2. 延迟加载

- 只有在实际需要时才加载模型
- 避免不必要的内存占用
- 支持按需加载

### 3. 批处理优化

```python
config = {
    'batch_size': 16,  # 根据GPU内存调整
    'max_workers': 4   # 并行处理数量
}
```

## 🎯 总结

这两个模型是质量分析器的核心组件：

- **语义相似度模型**: 提供智能去重功能
- **文本分类模型**: 提供内容相关性判断

它们通过 Hugging Face Hub 自动下载和管理，无需手动安装，使用简单且功能强大。如果模型不可用，系统会优雅降级，使用基于规则的方法进行质量检查。
