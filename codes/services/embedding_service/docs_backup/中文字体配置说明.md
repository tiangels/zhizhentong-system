# matplotlib 中文字体配置说明

## 问题描述

在 Mac 系统上使用 matplotlib 绘制包含中文的图表时，会出现以下警告：

```
findfont: Font family 'WenQuanYi Micro Hei' not found.
findfont: Font family 'SimHei' not found.
```

## 解决方案

### 1. 自动配置（推荐）

系统已自动配置中文字体，在导入 embedding_models 模块时会自动应用：

```python
from codes.aimodels.embedding_models import *  # 自动配置字体
```

### 2. 手动配置

如果需要在其他项目中使用，可以手动配置：

```python
import matplotlib.pyplot as plt
import warnings

# 设置中文字体
plt.rcParams['font.family'] = ['STHeiti', 'Arial Unicode MS']
plt.rcParams['axes.unicode_minus'] = False

# 禁用字体警告
warnings.filterwarnings('ignore', category=UserWarning, module='matplotlib.font_manager')
```

### 3. 使用配置模块

项目中提供了完整的字体配置模块：

```python
from config.font_config import configure_chinese_font
configure_chinese_font()
```

## 配置的字体

- **STHeiti**: 华文黑体（Mac 系统自带）
- **Arial Unicode MS**: 支持 Unicode 的 Arial 字体

## 测试验证

运行以下命令测试字体配置：

```bash
python tests/test_chinese_font.py
```

会生成测试图片 `chinese_font_test.png`，验证中文字体是否正常显示。

## 文件说明

- `config/font_config.py`: 完整的字体配置模块
- `tests/test_chinese_font.py`: 字体测试脚本

## 注意事项

1. 字体配置需要在导入 matplotlib.pyplot 之前执行
2. 如果仍有警告，可以忽略，不影响图表显示
3. 建议在项目初始化时统一配置字体

## 系统兼容性

- ✅ macOS: 使用 STHeiti 和 Arial Unicode MS
- ✅ Windows: 使用 SimHei 和 Microsoft YaHei
- ✅ Linux: 使用 WenQuanYi Micro Hei

## 故障排除

如果中文字体仍然显示为方块：

1. 检查系统是否安装了中文字体
2. 清除 matplotlib 字体缓存：删除 `~/.matplotlib/fontlist-*.json`
3. 重启 Python 环境
4. 使用 `python -c "import matplotlib.font_manager; matplotlib.font_manager._rebuild()"` 重建字体缓存
