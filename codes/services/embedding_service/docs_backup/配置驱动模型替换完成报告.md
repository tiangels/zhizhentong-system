## 配置驱动的模型替换机制

### 配置文件结构

```json
{
  "models": {
    "embedding": {
      "model_name": "BiomedCLIP-PubMedBERT_256-vit_base_patch16_224",
      "model_path": "/path/to/model",
      "huggingface_id": "google/BiomedCLIP-PubMedBERT_256-vit_base_patch16_224",
      "max_length": 512,
      "batch_size": 32,
      "vector_dim": 1024,
      "use_medical_tokenizer": true,
      "timeout": 300
    }
  }
}
```

### 模型替换流程

1. **配置读取**: 系统启动时自动读取 `model_config.json`
2. **路径验证**: 检查 `model_path` 是否存在
3. **模型选择**:
   - 如果本地路径存在 → 使用本地模型
   - 如果本地路径不存在 → 回退到在线模型
4. **自动初始化**: 根据配置重新初始化分词器和向量化器

### 替换模型的方法

要替换模型，只需修改 `model_config.json` 中的以下字段：

```json
{
  "embedding": {
    "model_name": "new-model-name",
    "model_path": "/path/to/new/model",
    "vector_dim": 768,
    "max_length": 512
  }
}
```

## 技术实现细节

### 配置管理

```python
def load_model_config():
    """加载模型配置文件"""
    config_path = Path(__file__).parent.parent.parent.parent / "ai_models" / "llm_models" / "model_config.json"
    try:
        with open(config_path, 'r', encoding='utf-8') as f:
            config = json.load(f)
        return config.get('models', {}).get('embedding', {})
    except Exception as e:
        print(f"Warning: 无法加载模型配置: {e}")
        return {}
```

### 模型路径检测

```python
# 加载模型配置
config = load_model_config()
model_path = config.get('model_path', self.model_name)

# 检查是否使用本地模型
if os.path.exists(model_path):
    self.logger.info(f"使用本地模型: {model_path}")
    self.use_online = False
else:
    self.logger.info(f"本地模型不存在，使用在线模型: {self.model_name}")
    model_path = self.model_name
    self.use_online = True
```

### 统一日志配置

```python
def setup_logging():
    """设置统一的日志配置"""
    log_dir = Path(__file__).parent.parent.parent.parent / "logs"
    log_dir.mkdir(exist_ok=True)

    logging.basicConfig(
        level=logging.INFO,
        format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
        handlers=[
            logging.FileHandler(log_dir / "embedding_service.log", encoding='utf-8'),
            logging.StreamHandler()
        ]
    )
    return logging.getLogger(__name__)
```
