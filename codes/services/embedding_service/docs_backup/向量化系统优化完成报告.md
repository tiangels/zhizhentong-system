## 使用方式

### 基本使用

```bash
# 构建多模态向量数据库
python run_vectorization.py --mode multimodal --sample_size 100

# 完整流程（预处理+向量化）
python run_vectorization.py --mode all --sample_size 100

# 测试检索系统
python run_vectorization.py --mode test
```

### 配置参数

```json
{
  "QUALITY_CHECK": {
    "enabled": true,
    "min_length": 10,
    "max_length_ratio": 1.2,
    "semantic_similarity_threshold": 0.95,
    "irrelevant_keywords": ["金融", "游戏", "娱乐"],
    "medical_keywords": ["疾病", "症状", "治疗", "诊断"]
  }
}
```
