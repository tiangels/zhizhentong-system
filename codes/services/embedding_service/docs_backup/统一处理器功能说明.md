## 📋 功能概述

已成功将 `general_text_preprocessing.py` 的功能合并到 `text_preprocessing.py` 中，并创建了独立的 `voice_preprocessing.py` 语音处理器，实现了清晰的职责分离架构。

## 🔧 主要改进

### 1. 分离式处理器架构

- **优化前**: 三个独立的处理器

  - `text_preprocessing.py` - 医疗文本处理器
  - `general_text_preprocessing.py` - 通用文本处理器
  - `image_text_preprocessing.py` - 图文处理器

- **优化后**: 三个专业处理器
  - `text_preprocessing.py` - 医疗文本处理器（专门处理文本文件）
  - `voice_preprocessing.py` - 语音处理器（专门处理语音文件）
  - `image_text_preprocessing.py` - 图文处理器（专门处理图文数据）

### 2. 支持的文件格式

各处理器现在支持以下文件格式：

#### 文本处理器 (text_preprocessing.py)

| 格式       | 扩展名          | 处理方式       | 数据类型检测     |
| ---------- | --------------- | -------------- | ---------------- |
| 文本文件   | `.txt`          | 按段落分割     | 根据文件名关键词 |
| CSV 文件   | `.csv`          | 按行处理       | 根据文件名关键词 |

| PDF 文件   | `.pdf`          | 按页提取       | 根据文件名关键词 |
| Excel 文件 | `.xlsx`, `.xls` | 按工作表行处理 | 根据文件名关键词 |

#### 语音处理器 (voice_preprocessing.py)

| 格式     | 扩展名                          | 处理方式       | 语音类型检测     |
| -------- | ------------------------------- | -------------- | ---------------- |
| 音频文件 | `.wav`, `.mp3`, `.m4a`, `.flac` | Whisper 转文本 | 根据文件名关键词 |

### 3. 数据类型自动识别

#### 文本数据类型识别

根据文件名自动识别文本数据类型：

```python
def _detect_data_type_from_filename(self, filename: str) -> str:
    """根据文件名判断数据类型"""
    filename_lower = filename.lower()

    # 医疗对话数据
    if any(keyword in filename_lower for keyword in ['dialogue', '对话', 'chat', 'conversation']):
        return 'dialogue'

    # VQA数据
    elif any(keyword in filename_lower for keyword in ['vqa', 'question', 'answer', '问答']):
        return 'vqa'

    # 医疗文档
    elif any(keyword in filename_lower for keyword in ['medical', '医疗', 'health', 'healthcare', 'diagnosis', '诊断']):
        return 'medical_document'

    # 默认为通用文档
    else:
        return 'general_document'
```

#### 语音类型识别

根据文件名自动识别语音类型：

```python
def _detect_voice_type_from_filename(self, filename: str) -> str:
    """根据文件名判断语音类型"""
    filename_lower = filename.lower()

    # 医疗对话语音
    if any(keyword in filename_lower for keyword in ['dialogue', '对话', 'chat', 'conversation', 'consultation']):
        return 'medical_dialogue'

    # 医疗讲座/培训
    elif any(keyword in filename_lower for keyword in ['lecture', '讲座', 'training', '培训', 'course']):
        return 'medical_lecture'

    # 医疗咨询
    elif any(keyword in filename_lower for keyword in ['consultation', '咨询', 'advice', '建议']):
        return 'medical_consultation'

    # 病历录音
    elif any(keyword in filename_lower for keyword in ['record', '病历', 'case', '病例']):
        return 'medical_record'

    # 健康宣教
    elif any(keyword in filename_lower for keyword in ['education', '宣教', 'health', '健康']):
        return 'health_education'

    # 默认为通用语音
    else:
        return 'general_voice'
```

## 📊 处理流程

### 1. 文件扫描

- **文本处理器**: 扫描 `text_data/raw/` 目录下的所有文本文件
- **语音处理器**: 扫描 `voice_data/raw/` 目录下的语音文件

### 2. 文件处理

- **文本处理**: 根据文件扩展名选择对应的处理方法（PDF、TXT、CSV、JSON、Excel）
- **语音处理**: 使用 Whisper 模型进行语音转文本
- **类型识别**: 根据文件名自动识别数据类型和语音类型

### 3. 数据清洗

- **文本清洗**: 应用统一的数据清洗规则、数据脱敏、保留医学特殊符号
- **语音清洗**: 音频预处理、去除静音、归一化、转录文本清洗
- **分词处理**: 对中文文本进行分词处理

### 4. 数据保存

- **文本数据**: 保存为 CSV 和 JSON 格式，包含数据类型统计
- **语音数据**: 保存为 CSV 和 JSON 格式，包含语音类型和时长统计
- **统计报告**: 生成详细的处理统计和摘要信息
