# 质量检查结果查看使用说明

## 概述

质量检查结果查看系统用于在向量化完成后查看整个过程中的质量检查结果，支持数据统计和图表展示。系统会自动收集向量化过程中各环节的质量检查数据，并生成详细的分析报告。

## 系统架构

### 1. 质量检查数据收集

- **数据来源**: 向量化过程中的质量检查器
- **存储位置**: `medical_knowledge/quality_stats/quality_stats.json`
- **数据内容**: 各阶段通过率、过滤原因、处理历史等

### 2. 质量检查结果查看器

- **文件位置**: `analyzer/quality_check_viewer.py`
- **功能**: 数据加载、图表生成、报告创建
- **输出格式**: JSON 报告、HTML 报告、PNG 图表

### 3. 质量检查分析脚本

- **文件位置**: `run_quality_check_analysis.py`
- **功能**: 命令行工具，一键生成完整分析报告

## 使用方法

### 1. 基本使用

```bash
# 在向量化完成后，运行质量检查分析
cd codes/ai_models/embedding_models
python run_quality_check_analysis.py
```

### 2. 高级使用

```bash
# 指定数据目录和输出目录
python run_quality_check_analysis.py --data-dir /path/to/data --output-dir /path/to/output

# 只生成JSON报告
python run_quality_check_analysis.py --format json

# 不生成图表
python run_quality_check_analysis.py --no-charts

# 指定统计文件和日志文件
python run_quality_check_analysis.py --stats-file /path/to/stats.json --log-file /path/to/log.log
```

### 3. 参数说明

| 参数           | 说明                      | 默认值                     |
| -------------- | ------------------------- | -------------------------- |
| `--data-dir`   | 数据目录路径              | `medical_knowledge`        |
| `--log-dir`    | 日志目录路径              | `logs`                     |
| `--stats-file` | 质量统计文件路径          | 自动查找                   |
| `--log-file`   | 向量化日志文件路径        | 自动查找                   |
| `--output-dir` | 输出目录路径              | `data_dir/quality_reports` |
| `--format`     | 输出格式 (json/html/both) | `both`                     |
| `--charts`     | 生成图表                  | `True`                     |
| `--no-charts`  | 不生成图表                | `False`                    |

## 输出文件说明

### 1. 图表文件

- **quality_overview.png**: 质量概览图表

  - 左图：文档质量分布饼图
  - 右图：各阶段质量检查通过率柱状图

- **filter_reasons.png**: 过滤原因分析图表

  - 左图：过滤原因柱状图
  - 右图：过滤原因分布饼图

- **quality_trend.png**: 质量趋势图表

  - 左图：各阶段通过数量
  - 右图：累积通过率趋势

- **processing_timeline.png**: 处理时间线图表
  - 处理阶段分布柱状图

### 2. 报告文件

- **quality_check_report.json**: JSON 格式的详细报告
- **quality_check_report.html**: HTML 格式的可视化报告

### 3. 统计文件

- **quality_stats.json**: 质量检查统计数据
  - 整体统计信息
  - 各阶段详细统计
  - 质量检查历史记录
  - 配置信息

## 数据统计说明

### 1. 整体统计

- **total_texts**: 总文本数量
- **completeness_passed**: 完整性检查通过数量
- **uniqueness_passed**: 唯一性检查通过数量
- **relevance_passed**: 相关性检查通过数量
- **vectorization_passed**: 向量化检查通过数量
- **final_passed**: 最终通过数量

### 2. 各阶段统计

- **completeness**: 完整性检查统计
- **uniqueness**: 唯一性检查统计
- **relevance**: 相关性检查统计
- **vectorization**: 向量化检查统计

### 3. 过滤原因统计

- **文本过短**: 文本长度小于最小要求
- **文本过长**: 文本长度超过最大限制
- **空白文本**: 空白的文本内容
- **仅含标点符号**: 只包含标点符号的文本
- **包含无关关键词**: 包含非医疗相关关键词
- **特殊字符比例过高**: 特殊字符占比超过阈值
- **重复文本**: 重复的文本内容
- **语义重复**: 语义相似的文本

## 质量检查流程

### 1. 数据收集阶段

```
向量化开始 → 质量检查器初始化 → 各阶段检查 → 统计数据记录 → 数据保存
```

### 2. 分析阶段

```
加载统计数据 → 生成图表 → 创建报告 → 输出结果
```

### 3. 查看阶段

```
打开HTML报告 → 查看图表 → 分析统计 → 优化建议
```

## 优化建议

### 1. 数据质量优化

- **定期检查数据源**: 确保输入数据的完整性和准确性
- **调整检查参数**: 根据实际需求调整质量检查阈值
- **监控通过率**: 关注各阶段通过率变化趋势

### 2. 系统优化

- **建立监控机制**: 定期运行质量检查分析
- **自动化报告**: 设置定时任务自动生成报告
- **告警机制**: 当质量指标异常时发送告警

### 3. 参数调优

- **最小文本长度**: 根据实际需求调整 `min_length` 参数
- **相似度阈值**: 调整 `semantic_similarity_threshold` 参数
- **特殊字符比例**: 调整 `special_char_ratio_threshold` 参数

## 故障排除

### 1. 常见问题

- **图表无法显示中文**: 检查字体配置模块是否正确安装
- **统计数据为空**: 确认向量化过程中质量检查器是否正常工作
- **文件路径错误**: 检查数据目录和日志目录路径是否正确

### 2. 调试方法

- **查看日志**: 检查 `quality_check_analysis.log` 文件
- **验证数据**: 确认 `quality_stats.json` 文件是否存在且包含数据
- **测试脚本**: 使用示例数据测试质量检查功能
