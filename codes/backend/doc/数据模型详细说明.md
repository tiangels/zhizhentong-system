# 智诊通系统数据模型详细说明

## 📋 概述

本文档详细说明智诊通系统后端使用的所有数据模型，包括数据库表结构、字段定义、关系映射和 Pydantic 模型。

---

## 🏗️ 数据库设计原则

### 设计原则

- **UUID 主键**: 所有表使用 UUID 作为主键，提高安全性和分布式支持
- **软删除**: 重要数据支持软删除，保留历史记录
- **时间戳**: 所有表包含创建时间和更新时间字段
- **JSON 字段**: 使用 JSON 字段存储灵活的元数据
- **外键约束**: 建立完整的外键关系，保证数据一致性

### 基础模型

所有模型继承自 `Base` 类，包含以下基础字段：

- `id`: UUID 主键
- `created_at`: 创建时间
- `updated_at`: 更新时间

## 👤 用户相关模型

### 1. User (用户表)

**表名**: `users`

**功能**: 存储用户基本信息

**字段定义**:

```sql
CREATE TABLE users (
    id VARCHAR(36) PRIMARY KEY,           -- UUID主键
    username VARCHAR(50) UNIQUE NOT NULL, -- 用户名（唯一）
    email VARCHAR(100) UNIQUE NOT NULL,   -- 邮箱（唯一）
    password_hash VARCHAR(255) NOT NULL,  -- 密码哈希
    full_name VARCHAR(100),               -- 全名
    phone VARCHAR(20),                    -- 手机号
    avatar_url VARCHAR(255),              -- 头像URL
    is_active BOOLEAN DEFAULT TRUE,       -- 是否激活
    is_verified BOOLEAN DEFAULT FALSE,    -- 是否已验证
    created_at TIMESTAMP DEFAULT NOW(),   -- 创建时间
    updated_at TIMESTAMP DEFAULT NOW()    -- 更新时间
);
```

**索引**:

- `idx_users_username`: username 字段
- `idx_users_email`: email 字段
- `idx_users_id`: id 字段

**关联关系**:

- 一对多: `UserSession` (用户会话)
- 一对多: `Conversation` (对话)
- 一对多: `Diagnosis` (诊断记录)
- 一对多: `UserPreference` (用户偏好)

### 2. UserSession (用户会话表)

**表名**: `user_sessions`

**功能**: 存储用户登录会话信息

**字段定义**:

```sql
CREATE TABLE user_sessions (
    id VARCHAR(36) PRIMARY KEY,           -- UUID主键
    user_id VARCHAR(36) NOT NULL,         -- 用户ID（外键）
    session_token VARCHAR(255) NOT NULL,  -- 会话令牌
    refresh_token VARCHAR(255),           -- 刷新令牌
    expires_at TIMESTAMP NOT NULL,        -- 过期时间
    is_active BOOLEAN DEFAULT TRUE,       -- 是否活跃
    ip_address VARCHAR(45),               -- IP地址
    user_agent TEXT,                      -- 用户代理
    created_at TIMESTAMP DEFAULT NOW(),   -- 创建时间
    updated_at TIMESTAMP DEFAULT NOW()    -- 更新时间
);
```

**外键约束**:

- `user_id` → `users.id` (CASCADE DELETE)

## 💬 对话相关模型

### 1. Conversation (对话表)

**表名**: `conversations`

**功能**: 存储对话会话信息

**字段定义**:

```sql
CREATE TABLE conversations (
    id VARCHAR(36) PRIMARY KEY,           -- UUID主键
    user_id VARCHAR(36) NOT NULL,         -- 用户ID（外键）
    title VARCHAR(255) NOT NULL,          -- 对话标题
    status VARCHAR(50) DEFAULT 'active',  -- 状态：active/archived/deleted
    conversation_type VARCHAR(50) DEFAULT 'chat', -- 类型：chat/diagnosis/consultation
    meta_data JSON,                       -- 元数据
    created_at TIMESTAMP DEFAULT NOW(),   -- 创建时间
    updated_at TIMESTAMP DEFAULT NOW()    -- 更新时间
);
```

**外键约束**:

- `user_id` → `users.id` (CASCADE DELETE)

**关联关系**:

- 多对一: `User` (用户)
- 一对多: `Message` (消息)
- 一对多: `Diagnosis` (诊断记录)

### 2. Message (消息表)

**表名**: `messages`

**功能**: 存储对话中的消息

**字段定义**:

```sql
CREATE TABLE messages (
    id VARCHAR(36) PRIMARY KEY,           -- UUID主键
    conversation_id VARCHAR(36) NOT NULL, -- 对话ID（外键）
    user_id VARCHAR(36),                  -- 用户ID（外键，可为空）
    role VARCHAR(50) NOT NULL,            -- 角色：user/assistant/system
    content TEXT NOT NULL,                -- 消息内容
    content_type VARCHAR(50) DEFAULT 'text', -- 内容类型：text/image/audio/video
    message_data JSON,                    -- 消息元数据
    is_processed BOOLEAN DEFAULT FALSE,   -- 是否已处理
    created_at TIMESTAMP DEFAULT NOW()    -- 创建时间
);
```

**外键约束**:

- `conversation_id` → `conversations.id` (CASCADE DELETE)
- `user_id` → `users.id` (SET NULL)

**关联关系**:

- 多对一: `Conversation` (对话)
- 多对一: `User` (用户，可选)

## 🎯 多模态相关模型

### 1. MultimodalInput (多模态输入表)

**表名**: `multimodal_inputs`

**功能**: 存储多模态输入数据

**字段定义**:

```sql
CREATE TABLE multimodal_inputs (
    id VARCHAR(36) PRIMARY KEY,           -- UUID主键
    user_id VARCHAR(36) NOT NULL,         -- 用户ID（外键）
    conversation_id VARCHAR(36),          -- 对话ID（外键）
    input_type VARCHAR(50) NOT NULL,      -- 输入类型：text/image/audio/video
    file_path VARCHAR(255),               -- 文件路径
    file_size BIGINT,                     -- 文件大小
    mime_type VARCHAR(100),               -- MIME类型
    processing_status VARCHAR(50) DEFAULT 'pending', -- 处理状态
    input_data JSON,                      -- 输入元数据
    created_at TIMESTAMP DEFAULT NOW(),   -- 创建时间
    updated_at TIMESTAMP DEFAULT NOW()    -- 更新时间
);
```

**外键约束**:

- `user_id` → `users.id` (CASCADE DELETE)
- `conversation_id` → `conversations.id` (SET NULL)

### 2. MultimodalOutput (多模态输出表)

**表名**: `multimodal_outputs`

**功能**: 存储多模态处理结果

**字段定义**:

```sql
CREATE TABLE multimodal_outputs (
    id VARCHAR(36) PRIMARY KEY,           -- UUID主键
    input_id VARCHAR(36) NOT NULL,        -- 输入ID（外键）
    output_type VARCHAR(50) NOT NULL,     -- 输出类型
    result_data JSON NOT NULL,            -- 结果数据
    confidence_score DECIMAL(3,2),        -- 置信度分数
    processing_time INTEGER,              -- 处理时间（毫秒）
    output_data JSON,                     -- 输出元数据
    created_at TIMESTAMP DEFAULT NOW()    -- 创建时间
);
```

**外键约束**:

- `input_id` → `multimodal_inputs.id` (CASCADE DELETE)

## 📈 性能优化

### 索引策略

- **主键索引**: 所有表的主键自动创建索引
- **外键索引**: 所有外键字段创建索引
- **查询索引**: 根据常用查询模式创建复合索引
- **全文索引**: 对文本内容字段创建全文索引

### 分区策略

- **时间分区**: 日志表按时间分区
- **哈希分区**: 大表按用户 ID 哈希分区

### 缓存策略

- **用户会话**: Redis 缓存活跃会话
- **配置信息**: Redis 缓存系统配置
- **知识库**: 向量数据库缓存

## 🔧 数据迁移

### Alembic 配置

系统使用 Alembic 进行数据库版本管理：

```bash
# 创建迁移
alembic revision --autogenerate -m "描述"

# 执行迁移
alembic upgrade head

# 回滚迁移
alembic downgrade -1
```
