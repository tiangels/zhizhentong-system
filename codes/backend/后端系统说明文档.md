# 智诊通 后端系统说明文档

## 📋 系统概述

智诊通后端基于 FastAPI 构建，提供用户认证、对话管理、诊断、知识检索、多模态处理等 API。采用模块化设计，内置 CORS、可信主机、全局异常、健康检查、自定义 Swagger、开放 API 安全模型等能力，并集成 Redis、PostgreSQL 与向量数据库等外部组件。

### 🎯 核心特性

- 高性能异步 API（FastAPI + Uvicorn）
- 生命周期管理（启动检查 DB/Redis，建表、健康日志）
- 全局中间件与异常处理、请求耗时统计
- 自定义 OpenAPI/Swagger UI 与 JWT 安全模型
- 模块化路由：认证、对话、诊断、知识、多模态、系统
- 健康检查 `/health` 与调试 `/debug/info`（DEBUG 模式）

---

## 🏗️ 技术栈与依赖

- 语言与框架：Python 3.9+、FastAPI、Uvicorn
- 配置：pydantic-settings
- 数据库：PostgreSQL（SQLAlchemy/ORM，见 `database.py`、`models/`）
- 缓存：Redis（`cache.py`）
- 向量/检索：与上游 检索/Embedding 服务对接
- 日志：标准日志与文件日志（`./logs/backend.log`）

依赖见：`codes/backend/requirements.txt`

## ⚙️ 配置与环境

文件：`app/config.py`

- 服务器：`SERVER_HOST`、`SERVER_PORT`（默认 0.0.0.0:8000）
- 数据库：`DATABASE_URL`（默认 Postgres）
- Redis：`REDIS_URL`、`REDIS_PASSWORD`
- JWT：`SECRET_KEY`、`ALGORITHM`、`ACCESS_TOKEN_EXPIRE_MINUTES`
- CORS：`CORS_ORIGINS`（开发含 8080）
- 上传：`UPLOAD_DIR`、`MAX_FILE_SIZE`、`ALLOWED_FILE_TYPES`
- 监控：`ENABLE_METRICS`、`METRICS_PORT`

环境变量示例：`codes/backend/env.example`

## 🔌 API 概览

仅列出关键端点，详细请以 `/docs` 为准。

### 系统

- `GET /health` 健康检查（状态、版本、外部服务）
- `GET /` 根信息（功能列表、文档链接）
- `GET /debug/info` 调试信息（仅 DEBUG）

### 认证（`app/api/auth.py`）

- `POST /auth/register` 注册
- `POST /auth/login` 登录（返回 `access_token` 与 `user`）
- `POST /auth/logout` 登出
- `GET /auth/me` 获取当前用户信息（需 JWT）
- `PUT /auth/me` 更新当前用户档案（需 JWT）

### 对话（`/api/v1` 前缀，`app/api/conversations.py`）

- `GET /api/v1/conversations/` 列表
- `GET /api/v1/conversations/{id}` 详情
- `POST /api/v1/conversations/` 创建
- `DELETE /api/v1/conversations/{id}` 删除
- `POST /api/v1/conversations/{id}/messages` 发送消息（同步）
- `POST /api/v1/conversations/{id}/messages/stream` 流式消息（SSE）

### 诊断/知识/多模态

- `app/api/diagnosis.py`、`knowledge.py`、`multimodal.py` 暴露对应占位或代理端点，便于前端联调与后续替换真实实现。

## 🔄 中间件与异常

- CORS：允许跨域（开发环境为 `*`）
- TrustedHost：限制来源（`ALLOWED_HOSTS`）
- 全局 HTTP 中间件：记录请求、统计耗时、附加 `X-Process-Time`
- 全局异常处理：`Exception`、`HTTPException` 统一 JSON 输出

## ⚠️ 故障排除

| 错误代码 | 描述           | 可能原因               | 解决方案                        |
| -------- | -------------- | ---------------------- | ------------------------------- |
| BE001    | 数据库连接失败 | URL/网络/权限错误      | 校验 `DATABASE_URL`，检测网络   |
| BE002    | Redis 连接失败 | 地址/密码错误、未启动  | 校验 `REDIS_URL`，启动服务      |
| BE003    | 未携带令牌     | 前端未传 Authorization | 在请求头添加 `Bearer <token>`   |
| BE004    | CORS 预检失败  | 跨域未配置正确         | 配置 `CORS_ORIGINS` 与允许方法  |
| BE005    | SSE 无数据     | 响应头/换行不规范      | 返回 `text/event-stream` 与换行 |
